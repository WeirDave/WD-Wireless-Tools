Ekahau Workflow Optimization Utility

Puts the device mix you plan for into an Ekahau project: which devices each person carries, on which usage profile, and how many. Build the mix once as a template, make it your default, and every project after that takes one number — how many people work on each floor.

Drop .esx file here or click to browse

  • Pick a template — your default is already picked — or build one
  • Check the people per floor and what happens to floors that already have devices
  • Apply and download the new copy; your file is not changed
