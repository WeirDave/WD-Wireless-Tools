2 — Turn it into a template

Everything is stored per person, so a template captured from a 500-person building applies correctly to a 200-person one. Check the per-person column below matches what you intended before saving.

3 — Apply a template to this project

An area you drew yourself is filled in, not replaced — your outline is kept exactly as it is and only the devices are written into it. A floor is left alone only when its area already carries capacity items, since overwriting those would discard numbers you set; tick the box to replace them.

Pick a template first.

Your project file is never written to. Applying builds a new copy and downloads it, so keeping it is your decision.
