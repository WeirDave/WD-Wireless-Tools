Steps
Your project file is never written to. Applying builds a new copy and downloads it, so keeping it is your decision.
1 — Apply a template to this project

Pick a template:

Floors hold different numbers of people, so every floor below has its own People on this floor box. Leave it blank to use the number above, type a number to override it, or type 0 to leave that floor alone.

An area you drew yourself is filled in, not replaced — your outline is kept exactly as it is and only the devices are written into it. A floor whose area already carries devices is kept as it is unless you choose otherwise above, or per floor below. That dropdown starts on the default saved in Settings → Capacity. Replacing sets the floor to the new number — it never adds to what was there, and any second capacity area on that floor has its devices cleared so it stops counting twice.
