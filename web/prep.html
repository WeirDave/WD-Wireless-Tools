WD Prep v…

1 — What to do
ft around the drawing

The margin is measured on the plan’s own scale, so the same setting means the same real distance on every sheet whatever its resolution. A plan with no scale falls back to 10 pixels. Normal is what the suite ships with; Wide and Extra wide leave noticeably more paper around the building if a crop that close to the walls is tighter than you like, and Parking lot keeps the site around it for outdoor APs. Pick Custom to type any distance. A margin never invents paper: if you ask for more than the sheet has, it keeps everything there is and stops at the edge. Each floor below says how much drawing it actually carries beyond the building, which is what tells you whether a big margin is a real choice or just “keep the whole sheet”.

This is the same setting as PlanTrim’s Margin, not a separate one — change it in either tool and both remember it, so a project you prepare here is cropped the way you set it there.

The first pass runs before there are any walls to measure, so the area covers the whole sheet. Once you have drawn walls, running Prep again tightens it to them. Only an area that is still exactly the whole plan is touched — a polygon you moved, redrew or cut around an atrium is left alone.

These always run in the order trim → areas → wall types, whichever you pick. A requirement area counts as something that has to stay on the plan, so an area put in before the trim holds the crop open — and the trim then reports that there was nothing to crop, which looks exactly like success.

2 — What that would do
Reading the project…

Your project file is never written to. Preparing builds a new copy, so keeping it is your decision. Opened from disk, that copy is written beside the original and nothing is uploaded — which on a large project is the difference between a preview that keeps up and one that does not.
