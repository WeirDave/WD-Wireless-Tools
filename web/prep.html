Stages · run in this order
Every stage opens on your saved defaults. If nothing needs a look, press Prepare straight away. The stages always run in this order: a requirement area put in before the trim would hold the crop open.

ft

Boxes you draw here are the same ones PlanTrim remembers for this project. Draw in either tool and both use them.

All floors

The margin is measured on the plan’s own scale, so it is the same real distance on every sheet, and it is the same setting as PlanTrim’s Margin. A margin never invents paper: asking for more than the sheet has keeps the whole sheet. Each floor says how much drawing it carries beyond the building.

Requirement areas

Manage templates
Per floor

Leave a floor’s box blank to use the number above, or type 0 to leave that floor alone. The choice for floors with devices starts on the default in Settings → Capacity. Replacing sets a floor to the new number and never adds to what was there. Only an area that still covers the whole plan is re-measured; one you drew or moved is left alone.

Wall types

Applied the way Quick Walls applies it: types the project lacks are added, types it has are set to the template’s colour, number key and attenuation, and walls already drawn stay on their types. To change the template itself, edit it in Quick Walls; Prep picks up the change when you come back.
