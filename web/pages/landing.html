WD Wireless Tools

A free suite of Ekahau workflow tools for wireless engineers. Organise cloud and local projects, remap wall types, label access points, trim oversized floor plans, convert scale, and turn an .esx into installer-ready reports.

It runs on your own machine. Your project files never leave it, there is no account, and there is no telemetry.

Install it

Install Python 3.10 or newer first — before anything else. On Windows, tick Add Python to PATH in the installer.

This is the one step that catches people out. On a stock Windows machine, typing python opens the Microsoft Store instead of running Python. If that happens, the install below will look like it worked and the app then will not start, with nothing on screen explaining why. Install Python from python.org, reopen your terminal, and check python --version prints a number.

Then run one command

Windows, in PowerShell:

irm https://raw.githubusercontent.com/WeirDave/WD-Wireless-Tools/main/install.ps1 | iex

macOS or Linux, in Terminal:

curl -fsSL https://raw.githubusercontent.com/WeirDave/WD-Wireless-Tools/main/install.sh | bash

It asks whether you want a git install (updates take seconds, because only what changed is downloaded) or a ZIP install (no dependencies, each update re-downloads the app). Either is fine, and you can switch later from Menu → About without reinstalling. The installer adds any missing Python packages and offers to start the suite.

Or download it by hand

Take the versioned WD-Wireless-Tools-vX.Y.Z.zip from the latest release — not GitHub's automatic "Source code" archive — extract it somewhere permanent, and run Start WD Wireless Tools.bat on Windows or Start WD Wireless Tools.command on macOS.

Every release ships a .sha256 checksum beside the ZIP. The in-app updater and both install scripts refuse to install a download whose hash does not match it.

Run it

Starting the suite opens a terminal window and then your browser at http://localhost:8675. The terminal is the app itself — leave it open while you work, and close it when you are done. Nothing is published to the internet; the address is local to your machine.

The first screen is a set of cards, one per tool. Pick one, drop in an .esx, and work from there.

The tools

Cloud ManagerCompare Ekahau Cloud projects against your local files. Find duplicates, match names, sync in bulk.
Quick WallsRemap every wall type in a project at once, with reusable templates and keyboard shortcuts.
AP LabelerSee your APs on the plan, choose a spatial order, and apply a naming pattern in one pass.
PlanTrimCrop the empty canvas off a CAD import and rebase every object so nothing moves.
ReportTurn an .esx into installer-facing PDFs — AP installation, antenna aim, BOM and more.
SquirrelSort loose project files into a predictable folder structure, after reviewing the result.
ScaleConvert between feet-and-inches, decimal feet, inches, metres and millimetres.

A typical first pass

  1. Open a project. Drop an .esx onto whichever tool you need. Files are read on your machine.
  2. Tidy the plan. PlanTrim crops an oversized CAD canvas; Quick Walls fixes wall types that came in wrong.
  3. Name the APs. AP Labeler applies a consistent naming scheme across a floor in one go.
  4. Produce the paperwork. Report builds print-ready documents for whoever is doing the install.
  5. Save and re-open in Ekahau. Tools that change a project write a new .esx — your original is not modified in place.
Printing reports: mixed portrait-and-landscape reports are verified in Chrome and Edge — each page comes out on the sheet it was laid out for. If a report ever prints clipped at the margin, use Match all pages in the report toolbar: it puts every page the same way round, which is always safe to print.

Where the browser tools went

Quick Walls, Scale and Report used to run here in the browser as a demo. They are now part of the desktop suite only, so that every tool behaves the same way and every setting is saved in one place rather than depending on which browser you happened to open. Install the suite above and you get all seven, including the ones that need access to your files and your Ekahau Cloud account.
