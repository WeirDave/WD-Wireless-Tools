WD Report

Turn an Ekahau .esx into installer-facing PDF reports — antenna azimuths, tilts, mount heights, floor-plan markers. Drop, print, done.

Quick Start

Step 1
Drop
Drop an .esx file onto the drop zone or click to browse. Everything runs in your browser — the file never leaves your machine.
Step 2
Choose
Pick a report template — AP Installation, Antenna Aim Sheet, Site Summary, Bill of Materials, or others.
Step 3
Configure
Tick the sections you want, filter the AP list, upload your logo. Options are report-specific.
Step 4
Print
Hit Print / Save PDF. The page is print-optimized — clean margins, hidden toolbars, page-breaks at section boundaries.

Reports That Ship Today

  • AP Installation — every AP plotted on floor-plan overlays with direction cones for directional antennas. Per-floor tables show AP names, vendor, model, floor, and building — and automatically add mount, height, azimuth, tilt, and antenna columns when directional APs are present. Handles omni, directional, and mixed buildings in one report. Optional antenna specs reference and naming audit.
  • Antenna Aim Sheet — one flat table for a clipboard: every directional AP with azimuth, tilt, mount height, floor. Compact mini-maps below the table give an at-a-glance sanity check per floor. Optional sign-off columns turn the sheet into an as-built.
  • Site Summary Sheet — one-page executive overview: AP + floor + building counts, radio band breakdown, top AP models, antennas in use.
  • Bill of Materials — AP quantities grouped by vendor and model, antenna quantities grouped by antenna type, with an "external antennas only" filter for procurement handoff.
  • Interference / Rogue Devices — iPhone / Android / MiFi hotspots and wide-channel rogue Wi-Fi picked up during the survey, scored by severity and mapped by floor.

AP Marker Labels

Markers on the floor-plan overview and the # column of every AP table use each AP's own name from the .esx — never an invented row number. That way marker "42" on the plan and row "42" in the table are always the same AP, and both cross-reference back to whatever you called that AP in Ekahau.

How the label is chosen

Your AP name looks like…Marker / # shows
SITE1-B1-01-01-AP4242 — the trailing "AP" designator is detected and shortened.
AP-07a07a — same rule, works with letter suffixes too.
Conference-Room-AlphaConference-Room-Alpha — no "APnn" suffix, so the full name is used.
00:11:22:33:44:5500:11:22:33:44:55 — same story. The label text scales down automatically so long names still fit on the marker.

The sidebar toggle

Reports that draw floor-plan markers expose a Short number labels on the plan option in the sidebar. On by default. Turn it off to force the full AP name onto every marker regardless of naming pattern — useful when your names look like "APnn" but the digits aren't the identifier you actually care about (e.g. building/floor-encoded schemes where the whole name matters).

Tip: Every floor's overview has a small legend line under it that spells out which mode is active — a quick reference for whoever's reading the printed PDF.

AP Filter & Grouping

The APs to include card on the Configure stage lets you filter down to the APs you actually want in the report. Search by name, toggle individual APs, or group by:

  • None — flat alphabetical list.
  • Color — use the color labels you assigned in Ekahau (great for zones or phases).
  • Floor — one collapsible group per floor plan.
  • Building — one group per building for multi-building sites.
  • Model — one group per vendor + model combination — handy for procurement.

Two report-level filters also gate which APs are eligible in the first place:

  • Include directional APs — APs whose antenna type has a specific azimuth. On by default.
  • Include omni APs — APs with only omni antennas. Off by default on the aim/placement reports because the sheet is about aiming; turn it on to include ceiling omnis with a placeholder in the azimuth cell.

Cover Page & Logo

Every report can prepend a cover page with your logo, the site name (pulled from the .esx file name), the AP count, and the date. Upload a logo once — it's cached in your browser (via localStorage) and persists across reports and sessions until you clear it.

Printing to PDF

Hit Print / Save PDF on the Review stage. The stylesheet forces:

  • Backgrounds and colors on (so your logo and marker cones actually print).
  • Sidebar, header, and navigation hidden.
  • Page breaks between sections — floors don't get sliced in half.
  • Table headers repeat on each printed page.

The output file name is auto-filled as Report - <report doc name> - <site name>.pdf.

Tip: If your browser's print dialog defaults to "Save as PDF" but strips backgrounds, look for More settings → Background graphics and turn it on. Without it, the cover and marker cones print blank.
