**Quick Walls.** Added **Warehouse Rack Wall** and **Warehouse Rack Wall - 16ft** to the bundled WD Template — two attenuation profiles for warehouse racking that weren't in the default set.

**Squirrel.** Create Project Folder can now create **multiple folders at once** — toggle "Create multiple folders at once" and pick which token varies per folder (e.g. one folder per building on the same site). The list of names can be typed by hand or **imported from a .txt, .docx, or .pdf file** (one name per line) via vendored in-browser docx/pdf readers, loaded on first use so a normal visit never pays for them. The four action cards on the landing page are now fully clickable (not just their buttons), the "last folder" hint moved onto the Organize card next to the button that uses it, and a hint now explains what "Show File Details" does before you've ever clicked it. Also: the native folder/file picker dialogs now run in an isolated subprocess instead of in-process — Tkinter's Tcl interpreter isn't thread-safe, and a picker request landing on a different Waitress worker thread while another was still open could previously crash with a "main thread is not in main loop" error.

**Cloud Manager.** A saved Ekahau Cloud session that's gone stale (signed out elsewhere, cookie expiry) used to make every API call chase the app's login redirect until it hit requests' 30-redirect cap, surfacing a useless "Exceeded 30 redirects" error. That's now caught and turned into "Your Ekahau Cloud session has expired. Reconnect (Settings → Forget login, then sign back in)." — and the stale session is dropped so the next call re-validates instead of retrying the same dead cookies forever.

**Report.** New template: **Predictive Design / AP Placement** — the same floor-plan overlay and large-floor zoomed-section engine as the Directional Antenna report, but placement only (no mount/azimuth/tilt table or antenna spec page). For handing installers exact AP locations before construction, or design sign-off before a build.

**Launcher.** `run.bat` / `run.command` now run a best-effort `git pull` before starting the server, so double-clicking the launcher on any checkout picks up whatever's been pushed to GitHub instead of silently running whatever was on disk from the last manual pull. Skips quietly if the folder isn't a git checkout or git isn't on PATH; git's own conflict/no-network handling means it never overwrites local edits. The startup console banner also got a small ASCII-art "WD" logotype — plain backslash/underscore/pipe glyphs only, no unicode box-drawing, to preserve the existing cp1252/piped-stdout safety guarantee.
