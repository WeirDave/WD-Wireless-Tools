# The browser tab shows the version number

Suite **2.246.18**.

## What changed

### Every page

- **The browser tab title now includes the version.** Home, the User Guide, Settings and Setup show the suite version, for example "WD Wireless Tools v2.246.18". Each tool shows its own version followed by the suite it shipped in, for example "WD Cloud Manager v4.93.0 (suite v2.246.18)". Two tabs of the same tool, or a tab left open across an update, can now be told apart without opening About. Release notes are written against the suite version, which is why a tool's tab names both.
- **The Report is the exception once a project is loaded.** Its tab title is the name a saved PDF gets, so the version is shown only on the empty page and is never added to a report's title.

## Verified

- The title text is built by the shared page script and checked in Node against the real `versions.json`: suite pages, tool pages, repeated application without the number stacking, and a title already replaced by the page being left alone.
- Every tool page names a tool that has an entry in `versions.json`.
- The full suite passes.
