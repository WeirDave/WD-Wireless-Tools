## What's new

### Coverage Cell Boundary, live

Drop an `.esx`, pick **Coverage Cell Boundary** from the picker, and each floor plan now gets an overlay with a translucent circle per AP at that AP's estimated **−67 dBm boundary** — the standard threshold for reliable voice and video. Overlapping circles show handoff zones; gaps between them show weak-signal areas. Circles are color-coded by radio band (2.4 GHz blue, 5 GHz green, 6 GHz purple) and numbered so the pin at each AP center matches the row it gets in the "Cell sizing per AP" legend table underneath.

Below the overlays, the sizing table lists every AP with its TX power, antenna gain, computed EIRP, and both the **−67 dBm** and **−80 dBm** radii. A methodology section at the end spells out exactly what the model does and does not account for.

**Sidebar controls.**

- **Primary coverage cell (−67 dBm)** — on by default. Turn off if you only want the outlined rings.
- **Signal-strength rings** — off by default (they get busy on dense floors). When on, adds outlined circles at Strong (< −55 dBm), Fair (< −75), and Weak (< −80) with solid / dashed / dotted stroke styles respectively.
- **Color-code by band** — on by default. Off gives everything a neutral nav-blue.
- **AP number labels** — on by default.
- **Cell sizing table** — on by default. The per-AP tabular breakdown.
- **Include directional APs / Include omni APs** — both on by default.

### The physics, briefly

Radii come from a log-distance path-loss model:

```
RSSI(d) = EIRP − PathLoss(d)
PathLoss(d) = C_band + 30·log10(d_meters)     (n = 3, indoor)
C_band: 40 dB at 2.4 GHz · 46.5 at 5 GHz · 48 at 6 GHz
```

Solve for `d` given a target RSSI and you get the ring radius. Convert from meters to floor-plan pixels via the `metersPerUnit` on each floor plan. EIRP per radio = `transmitPower + antenna.maxGain`.

**What it does not model.** Walls, floors, and material attenuation. Directional antennas are drawn as circles (their gain enlarges the radius uniformly rather than shaping a sector). Interference, channel overlap, client sensitivity, airtime utilisation — all outside the scope of this drawing. The methodology section in the report itself says this plainly so a printed copy carries its own caveats.

Read the report as: *"does the map look reasonable, and where are the obvious weak-signal gaps."* Not a substitute for a measured predictive survey.

## Verification

1. Open `/report`, drop any `.esx` that has APs placed on floor plans, pick **Coverage Cell Boundary**. Configure step shows seven toggles; Review renders a translucent overlay per floor plus the sizing table and methodology block.
2. Toggle **Signal-strength rings** on. Each AP gains outlined solid / dashed / dotted rings at the −55 / −75 / −80 thresholds. Toggle **Primary coverage cell** off with rings still on — you get an outline-only view.
3. Turn **Color-code by band** off. Every cell becomes nav-blue; band chips disappear from the floor key.
4. Verify computed radii are sane by picking any row in the table — a 20 dBm AP with a 3 dBi antenna at 5 GHz should give a −67 dBm radius around 17-19 m.
