Create Project Folder gets a tokenized naming template. Define your folder-name pattern once, and the dialog fills in per-token fields instead of a single free-form input.

Suite `v1.18.0 → v1.19.0`. Squirrel `v1.16 → v1.17`.

## What's new

Settings has a new field: **Create Folder naming template**. Enter a template like:

```
{code} - {name}, {city}, {state} {zip}
```

Available tokens: `{code}`, `{name}`, `{city}`, `{state}`, `{zip}`, `{date}` (auto-filled with today's ISO date, readonly).

**When a template is set**, the Create Project Folder dialog changes shape:

- The single "Folder name" input is hidden.
- A 2-column grid of token inputs appears — one per unique token in your template.
- A **live preview** below the fields shows the composed folder name as you type.
- Non-`{date}` values are remembered per-token in `localStorage`, so re-opening the dialog pre-fills what you used last time. `{code}` and `{name}` clear each open (they're the site-specific bits); `{city}`/`{state}`/`{zip}` persist.
- Empty template = single free-form input mode (today's behavior).

Enter submits from any token input, matching the existing behavior of the single-input mode.

## Verified end-to-end

Template `{code} - {name}, {city}, {state} {zip}`:

- 5 token inputs render (`code`/`name`/`city`/`state`/`zip`).
- Preview updates on every keystroke.
- Fill `SITE-001`, `1400 Example Corp`, `Springfield`, `CA`, `90001` → preview shows `SITE-001 - 1400 Example Corp, Springfield, CA 90001`. Exact match.

Template `{code}_{date}`:

- 2 token inputs render.
- `{date}` auto-populates with `2026-07-29` (today's ISO date) and is readonly.

Empty template:

- Token fields hidden, single "Folder name" input visible. Legacy behavior intact.
