# Prep: keep or replace the devices floor by floor

Suite **2.190.0** ships **Prep 1.14.0**. The Prep page shows the Prep number, not the suite number.

## What changed

### Prep → Put a requirement area on every floor

- **Each floor that already has devices can now take its own choice.** Before this release, one **Floors that already have devices** choice applied to every floor, so a project could not have one floor replaced and another kept in the same pass. Capacity has had this since 2.179.0.
- **Where it is:** Prep, step **2 — What that would do**, the **Requirement areas** card. Every floor that already has devices shows a **This floor** dropdown under its **People on this floor** box, with the number of devices it has now. The choices are **Keep them**, **Replace devices, keep outline** and **Replace devices, redraw outline**. Floors with no devices have nothing to choose and show no dropdown.
- **Default:** each floor follows **Floors that already have devices** in step 1, which starts on the value saved in **Settings → Capacity**. Picking a different choice for a floor overrides it for that floor only. Choosing the same value as step 1 hands the floor back to it, and changing the step 1 dropdown resets every floor to the new choice.
- **Keep on a single floor also protects a placeholder area.** Prep re-measures a requirement area that still covers the whole plan, when **Re-measure areas that still cover the whole plan** is ticked. A floor set to **Keep them** on its own is now left out of that, so its area and devices stay exactly as they are. Floors that only follow the step 1 default are re-measured as before.
- **Prepare** uses the same per-floor choices as the preview. The choices are cleared when another project is opened.

## Verified

- A project with devices on two floors, prepared with step 1 on **Keep them as they are** and one floor set to **Replace devices, keep outline**, keeps the first floor at its original count and sets the second to the new count, read back from the prepared project. The reverse, step 1 on replace with one floor set to **Keep them**, also holds.
- A floor set to **Keep them** that carries a whole-plan placeholder keeps that area, its outline and its devices; with only the step 1 default, the placeholder is re-measured as before.
- On the real Prep page, only a floor that already has devices shows the dropdown. Its choice is sent with the preview and with **Prepare**, choosing the step 1 value clears it, changing step 1 resets every floor, and opening another project starts with no floor choices.
- These checks fail if the pipeline stops passing the per-floor choices to the writer, if a floor set to **Keep them** is re-measured, or if the page stops sending the choices.
