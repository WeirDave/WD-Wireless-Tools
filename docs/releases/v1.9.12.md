Fix: the banner's "Restart now" button now reliably relaunches instead of falling through to the batch file's "Press any key" pause.

## What changed

### The bug
Clicking "Restart now" was signalling the launcher to loop via Python's exit code 42 (`os._exit(42)`). On Windows the code doesn't always survive the round trip through Waitress's shutdown + cmd's `%ERRORLEVEL%` capture — you'd end up at the batch file's `pause` line instead of a fresh server. Clicking Restart again from the still-open browser tab did nothing (the server was gone), and the only recovery was double-clicking `run.bat` manually.

### The fix — sentinel file, not exit code
`server.py` now drops a `.restart_requested` marker file right before exiting, and the launcher (`run.bat` / `run.command`) checks for that file at exit time:

- Marker present → delete it, `GOTO start` (relaunch on the same port).
- Marker absent → `pause` (or exit on macOS) so real quits and crashes aren't fought.

The launcher also deletes any stale marker at the *start* of every loop iteration, so a marker left behind by an aborted cycle can never cause a spurious relaunch on next launch.

The marker file survives whatever quirks Waitress + cmd want to inflict on the exit code, so this path is unambiguous.

### Side fix — ASCII-safe startup banner
The `WD Wireless Tools → http://localhost:8675/` line used a unicode arrow that crashed Python under any cp1252 stdout (background tasks, some non-utf8 consoles), and the crash happened *before* the port bind, so a captured launch never even reached `serve()`. Swapped for `->` — one less way this can bite in unusual environments.

### Side fix — "Not assigned" pill no longer looks like "Measured"
On unassigned cloud projects, the warning pill was amber-on-amber (`#9a3412` on `#ffedd5`), which sat right next to the amber-on-amber "Measured" type badge (`#92400e` on `#fde9c8`). Same hue family, same weight — the two blurred together and the warning stopped reading as a warning.

Retinted the "Not assigned" pill (and the matching "Assign to site" 📎 button) to red — `#dc2626` on white in light mode, `rgba(220,38,38,0.28)` in dark — so it's now in a completely different hue family from the amber type badges and unmistakably reads as "attention, click to fix."

### Version bumps
- Suite `v1.9.11 → v1.9.12`

## Files changed
- `server.py` — `RESTART_EXIT_CODE` removed; `_restart_after_response()` now writes `.restart_requested` then `os._exit(0)`. Startup banner uses ASCII `->`.
- `run.bat` — loop guard swapped from `IF %ERRORLEVEL% EQU 42` to `IF EXIST .restart_requested`; `del` on entry + on relaunch to keep the marker transient.
- `run.command` — same swap using `[ -f .restart_requested ]`; `rm -f` guards to match.
- `.gitignore` — `.restart_requested` added so an aborted cycle never leaks into a commit.
- `web/assets/versions.json` — suite bump.
- `web/assets/wd-tools.css` — `.ptype-tag.pt-unassigned` and `.icon-btn.assign-btn` retinted to the red family so they can't be mistaken for the amber "Measured" pill.
