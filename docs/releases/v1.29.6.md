This release is a polish-and-flexibility pass across the suite: **Squirrel's Create Project Folder flow becomes genuinely customizable**, every tool gets a stronger visual identity, Scale receives a cleaner landing experience, and the launchers stop overlooking partially installed dependencies.

Suite `v1.28.0 → v1.29.6`. Squirrel `v1.19 → v1.21`. Scale `v1.3 → v1.4`.

## What's new

### 1. Create exactly the project structure you need

Squirrel's **Create Project Folder** modal no longer treats the configured destination list as untouchable. Each proposed subfolder now has an editable name, so `images` can become `installer-photos`, `reports` can become `closeout-docs`, or any other project-specific wording can be used without changing the global Squirrel configuration.

The modal also supports one-off folders through **+ Add subfolder**. Ad-hoc entries appear alongside the configured destinations, can be removed before creation, and apply only to the project being created. Checkboxes still control which rows are included.

The backend accepts the final literal folder names selected in the modal, sanitizes filesystem-invalid characters, removes duplicates, and preserves the historical behavior for older clients that do not supply a subfolder list.

A follow-up layout pass widened the modal and fixed the editable rows wrapping under broader modal input rules. The checkbox, color swatch, editable name, status pill, and remove control now stay aligned as a single readable row.

### 2. A real per-tool color system

The suite's home-page cards already gave each tool a recognizable accent. Those identities now carry through the tools themselves:

- **Cloud Manager** — blue
- **Quick Walls** — green
- **WD Report** — teal
- **WD Scale** — purple
- **WD Squirrel** — amber

Each tool's header bar receives a restrained accent tint in both dark and light themes. The complete title—not only the `WD` prefix—uses the tool color, while version labels remain neutral gray. The same treatment covers secondary surfaces such as Quick Walls' Visual Wall Swap header and Report's wizard/review bars.

This went through a couple of iterations during the release: a partial-title treatment was tried and reverted before settling on the full-title color system. A final cascade fix removed an older blue-soft span rule that was still overriding the `WD` portion of several titles.

### 3. Scale gets a cleaner front door

WD Scale now uses the full Scale logo as the hero graphic instead of squeezing a tiny icon into the topbar title. The logo sits above **Scale & unit converter**, matching the hierarchy used by the other tool landing pages.

The introduction has also been split into a short explanation and a separate row of accepted-input examples, making the page easier to scan without changing the converter itself.

### 4. Launchers verify every dependency

The Windows and macOS launchers previously checked only whether Flask was installed. A machine with Flask but without Waitress, Requests, or `browser_cookie3` could therefore skip dependency installation and silently run in a degraded or broken state.

Both launchers now test all four required imports before deciding installation can be skipped. First launch remains automatic; the check is simply complete now.

## User-visible behavior change

- Squirrel project subfolders can be renamed inline for one project.
- One-off subfolders can be added without changing Settings.
- The Create Project Folder modal is wider and its rows no longer wrap incorrectly.
- Tool titles and header bars consistently use their home-card accent colors.
- Scale opens with its full logo and a clearer explanation/examples hierarchy.
- Partially installed Python environments now trigger the missing dependency installation instead of silently continuing.

## Verification

1. Open Squirrel → **Create Folder…**. Rename a checked destination, add a one-off subfolder, remove another row, and create the project. Only the checked rows are created with the displayed names.
2. Resize the Create Folder modal area: each subfolder row remains aligned without its text input dropping beneath the checkbox.
3. Visit all five tools in dark and light modes. Each title and header bar matches its home-page card accent; version text remains neutral.
4. Open Scale. The full logo appears above the hero title, followed by the explanation and supported-input examples.
5. On a Python environment missing any one required package, launch with `run.bat` or `run.command`. The launcher detects the missing import and installs from `requirements.txt`.
