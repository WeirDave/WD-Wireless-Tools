# Settings: no card wraps, and choosing one no longer changes its size

Suite **2.246.21**. Tool versions are unchanged.

## What changed

### Settings (the panel over Home or over any tool, and the page at Menu → Suite Settings)

- **Choosing a card no longer makes its text wrap.** The arrow on the open card used to take room from its description, so choosing Quick Walls pushed "reveal" onto a second line and moved every card below it down. The arrow now sits over the card's right edge, and every card keeps the same room for its text whether it is open or not.
- **The PlanTrim card is now "Other tools".** "PlanTrim, Rename and the rest" always wrapped onto two lines. The section holds the same overview of what PlanTrim, Rename and AP Labeler save, and its title across the top of the box reads "Other tools" to match. The Settings section in the User Guide has the same name.
- **Card descriptions are shorter**, so none of them runs onto a second line or is cut off: "Project folder, launcher", "Folders and sorting bins", "File types, sorting rules", "Merge rule, view, login", "Client, units, sections", "Template, folder reveal", "Floors that have devices", "What other tools save" and "Export, import, copies".
- **A window narrower than about 1000px shows the cards without their description line**, since a narrow card cannot hold it beside the icon on one line.

## Verified

- A new browser test, run in Firefox, Chrome and Edge, chooses each of the nine sections in a tall window and a short one and fails if any card's name or description wraps or is cut off, or if any card changes size when a section is chosen. Before the change it failed on the PlanTrim card in all three browsers; with the change it passes in all three.
- The stylesheet-scale and tool-colour checks pass.
