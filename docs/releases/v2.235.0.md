# Quick Walls: a notice offers to merge a wall type's copies into the original

Suite **2.235.0**, Quick Walls **7.79.0**. Every other tool is unchanged.

## What changed

### Quick Walls

- **A notice above the wall type cards lists copies and offers to merge them.** A project can hold the same wall type more than once: Ekahau names a copy "Window, Thick(Copy)", **Clone** names one "Window, Thick (Copy)", and the same name can be added beside an existing type. Each of these is a card of its own and the walls drawn with it are counted apart. When the project has any, the notice reads "N wall types are copies of another" and has one line per type, saying which type it keeps and which it removes, with the number of drawn walls on each. It is hidden when there are none.
- **Merge** on a line merges that type's copies. **Merge all**, at the foot of the notice, merges every line.
- **Merging moves the walls and removes the copies.** Walls drawn with a removed copy move to the type that is kept, so no wall is left without a type. The kept type is the original when the project has it, otherwise the copy with the most walls, and it keeps its own colour and settings. A kept copy with no original in the project loses "(Copy)" from its name.
- **A confirmation comes first.** It names each type it will remove, with its wall count, and the type it is kept under.
- **Nothing is written until the project is saved.** Closing and reopening the file undoes a merge.
- **The same rule decides what counts as one type.** Case and spacing are ignored, and so is a trailing "(Copy)", "(Copy)(Copy)" or "(Copy 2)", with or without a space before it. A name that only contains the word elsewhere, such as "Copy Station Wall", is left alone. Visual Swap uses this one rule, so its lists and these cards agree.

## Verified

- A project with same-name copies, "(Copy)" and "(Copy)(Copy)" types with and without an original, and a name that only contains the word "Copy" is opened in the real page in Chrome, Edge and Firefox, and the real **Merge** and **Merge all** buttons are pressed. The remaining wall types, the wall type each wall in the project file points at, and the cards shown are read back.
- Declining the confirmation changes nothing. The confirmation names every removed type with its wall count. Merging one line leaves the other lines alone.
- With the removal of copies left out, and separately with the walls not moved, these checks fail.
- The notice was viewed in Chrome.
