# Cloud Manager: Sync all leaves out other people's projects

Suite **2.233.0**, Cloud Manager **4.90.0**. Every other tool is unchanged.

## What changed

### Cloud Manager

- **Sync all downloads only projects owned by the signed-in account.** The **Sync all** dialog (the **Sync all** button in the toolbar) has a section headed "Download N cloud projects you have no local copy of". Previously it listed every such project that the account could see, including projects owned by other people, each ticked by default. Projects that belong to someone else are now left out of the run.
- **The dialog says how many were left out.** A line at the end of the dialog reads "N cloud projects belong to other people and are not part of a sync. Download one from its own row if you want it." The same sentence is shown when other people's projects are the only new ones and there is nothing else to sync.
- **Projects with no recorded owner are still included.** A project whose owner is not known is treated as the signed-in account's own, as elsewhere in Cloud Manager.
- **Downloading someone else's project is unchanged.** It remains available from that project's own row.

## Verified

- The sync planner is run on a list mixing the signed-in account's projects, other people's projects and projects with no recorded owner, both at the top level and inside a site. Only the first and last groups are offered for download; the others are counted.
- With the previous code the same checks fail.
- When every new project belongs to someone else, the message names the count and nothing is queued.
