# Report: the section grid is remembered for each project

Suite **2.241.0**. Report **2.74.0**. Other tools are unchanged.

## What changed

### Report

- **The section grid stays set.** In the options panel, **Configure grid…** (under **Split large floor plans into zoomed sections**) opens the grid dialog. Pressing **Done** now saves the columns and rows, each floor's crop box and the combined sections for that project. Picking a different report, or closing the file and opening it again, brings them back. Previously all of it was cleared on either action.
- **A new project starts from the last size.** A project that has not been set up opens with the columns and rows most recently set on any project. Crop boxes and combined sections are never carried to another project. A line under the button says where the grid came from: *Remembered for this project.* or *Starts from the last grid size you set.*
- **Auto can be chosen and kept.** **Reset to Auto** followed by **Done** clears the size and keeps the project on Auto. Before, the numbers Auto happened to give were written down as a fixed size.
- **A saved crop is skipped when it would cut off an AP.** If a project was revised and an AP now falls outside a saved crop, that crop is not applied and a message names the floor.
- Combined sections are applied only when the grid still has the columns and rows they were cut from.
- The grid is stored on the computer in the Report data folder (`section_grids.json`, beside the column grid file), not in the `.esx` and not in the project folder. At most 500 projects are kept; the oldest are dropped first.

### User manual

- The Report chapter, under *Large floors — section splitting*, replaces the note that the grid is not saved.

## Verified

- New tests drive the real Report page against the real store: the grid survives switching report and reopening the file, a new project takes only the last size, Auto is kept, an unsafe crop is skipped, and a server that cannot answer leaves the grid on Auto. Each rule fails when removed.
- The store tests cover rejected sizes, crops outside the plan, combined sections outside their grid, damaged and oversized files, and the endpoint.
- Full test suite passes.
