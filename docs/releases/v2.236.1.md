# Cloud Manager: files missing survey data are now marked in the Projects list

Suite **2.236.1**. Cloud Manager **4.91.1**. Other tools are unchanged.

## What changed

### Cloud Manager: Projects list

- **A local file whose surveys refer to missing signal and noise samples is now marked on its row.** Version 2.236.0 added the check and the **Re-download survey data** button, but the list did not pass the result to the page, so no row showed the marker and no file was counted as out of step. The marker, the button, the out-of-sync filter and totals, and the *survey data missing* verdict in **Sync everything** now appear as described in the 2.236.0 notes.
- **The Sites tree carries the same information.** A file in a site folder is checked the same way as one in the Projects list.

## Re-downloading existing files

Files downloaded before 2.236.0 remain without their samples until they are downloaded again. Use **Re-download survey data** on a marked row, or **Sync everything** and tick the listed files.

## Verified

- The real Projects list and Sites tree builders are run over a folder containing a file missing its samples, a complete file and a file with no surveys. The missing count arrives on the first only, in both builders. The test fails when either builder stops copying it.
- The full suite passes.
