# A functional review of every tool: data-loss, wrong-target and dead-control fixes

Suite **2.208.0**: Cloud Manager **4.80.0**, Quick Walls **7.73.0**, Report **2.68.0**, Squirrel **1.29.0**, PlanTrim **2.2.0**, Prep **2.4.0**, Scale **1.6.3**, AP Labeler **2.17.0**, Capacity **1.9.0**.

Every tool was reviewed for what goes wrong in use. Each fix below was reproduced against the real code with invented projects first, and each carries a test that fails on the previous version.

## What changed

### Cloud Manager

- **Duplicate Projects → "Delete all N extras" acts only on what is shown.** It used to delete across every cluster, ignoring the filter and search, and in a cluster with no matched copy it deleted every copy. It now touches only the clusters on screen and always keeps the newest copy where nothing is matched. The button hides when the filtered list is empty.
- **Merge shows "When a file already exists" again.** The Keep newer / Keep both / Skip choice was never visible, so the saved rule overwrote files silently. It now appears whenever the merge has a conflict.
- **Renaming a local project updates the name inside the .esx.** Every local rename (local only, both sides, or cloud first with the partner ticked) failed to align the stored project name and left the pair showing a name difference.
- **"Make matching pairs agree…" and Verify work on ticked rows.** Both were permanently disabled since each side of a pair got its own checkbox.
- **Bulk Move and bulk Delete leave colleagues' projects out**, and name them with their owner, as the row menu and Share already did. Ekahau refused those changes anyway.
- **Bulk Share lists project names, not ids,** and no longer offers a site as a project.
- **Downloads land in the paired local folder.** A cloud site paired with a differently named folder used to get a new folder under the cloud name.
- **A row's Upload files the project under its site.** A file inside a site folder used to upload unassigned.
- **Sync everything on the Sites tab** no longer tries to download sites as projects, and a failed download is no longer counted as "updated".
- **After "Local newer · replace cloud", later local edits push normally.** The sync point recorded the wrong cloud date, so the next local edit made the pair read as changed on both sides and Sync everything refused it.
- **Replace says what did not happen**: a failed site assignment or sync-back appears as a warning instead of a clean success. The list of people who lose access now reads the project's real shares; before, it was always empty.
- **Replace refuses a project proven to belong to someone else** before uploading, instead of leaving two copies.
- **Refresh group shares keeps each project's own role.** It used to apply one project's group role to all of them. If Ekahau fails partway, the message names every project left without the group share.
- **Unfiled cloud projects matched to a local file show newer or older** on the Sites tab, and Sync everything plans them.
- **Overwriting a local file from the cloud is all or nothing**: a failed download no longer leaves a truncated .esx. "Not a match", manual pairings and External marks are saved the same way.
- A name differing only in capitals is no longer reported as a rename. "&" in a name shows once, not as "&amp;". Live refresh keeps the ticks on Duplicate Projects. Two texts were corrected: the local-delete tooltip mentions the cloud copy only when there is one, and "None of these" points at **Manage Not-a-Match** in the main menu.

### Quick Walls

- **The "Set key" / "Key N" button on a wall card opens the 1–9 shortcut menu.** It did nothing.
- **Applying a template keeps types with non-Latin names apart.** Names in Cyrillic, Greek or CJK all matched each other, so one type was overwritten and others never added.
- **An added template type gets its own id** when the project already uses the template's id for a different type.
- **A custom type named like a stock one stays custom.** "Concrete" used to take Ekahau's stock key and be overwritten by a template's "Wall, Concrete".
- **Save and Import ask before replacing a saved template**, naming it. Names that differ only in punctuation share a file and used to overwrite each other silently. Import never asked.
- The wall audit reads heights written with a foot mark (`16'`). Its `--fix` text no longer promises a copy that is not kept. A template repeating a type now writes the entry the preview described.

### Report

- **AP Installation always prints Mount, Height and Antenna.** On a floor where every AP was omni (the usual ceiling case), those columns were missing. Azimuth and Tilt still appear only where an AP is directional.
- **APs outside a crop are named.** An AP outside the crop drawn in **Configure grid…** was on no section sheet with no mention. The floor's sheet now lists them, the grid dialog warns while the crop is drawn, and **Apply to all floors** names what it cut on each floor.
- **Summary, BOM and Interference include notes on omni APs.**
- **Opening a second project no longer keeps the first project's grid, crop or combined sections.**
- **A radio with no stored power prints "—"** instead of an invented 15 dBm.
- **The contents page states the number of section sheets that print**, not columns × rows.
- **"Reset to shipped defaults" works** when it appears after a change. The page's security policy blocked it.
- **Group by colour makes one group per colour** (both greys Ekahau writes are one Gray). The Antenna Aim Sheet sorts AP2 before AP10.

### Squirrel

- **Organize no longer stops partway with no undo.** A folder that cannot be read or written is reported as an error, the other sites carry on, and whatever moved can be undone. The preview names folders it could not read.
- **Preview and Organize follow one rule** for loose files in the root. Before, the preview could list moves that Organize then did not make.
- **A run that moves nothing keeps the previous undo**, and the preview shows the exact name a file will get when two would collide.
- **" (root folder)" no longer appears in renamed file names.**
- **Rename → Undo reverts the rename just made, in this folder.** After switching tabs it used to revert an older operation from another folder. It never overwrites a file saved since. Anything it could not restore is listed and stays undoable.
- **Renames that change only capitals apply on Windows.** They used to be skipped as "target exists".
- **The rename preview flags names already on disk** (case-insensitive), and the Rules tab sends only rows that can rename.
- A rename can no longer write outside the chosen folder. The Rename folder picker says when it cannot open. Gap Report and CSV prefill skip Squirrel's own folders.

### PlanTrim and Prep

- **A drawn box removes what it cuts.** When it cut every object of one kind on a floor (the only AP, the only exclusion area), those objects were written back uncut, off the plan, while the AP's radios were dropped.
- **Re-running Prep on its own output no longer crops it twice.** A saved box from the original sheet was reapplied to the already cropped plan, deleting anything placed since. Such a box is now set aside, and the Trim step says so.
- **Survey paths in the older single `surveys.json` move with the crop.**
- **Prep with Trim, Areas and "Re-measure" crops the plan.** The placeholder area the same run was about to replace used to stop the trim ("already fills 100%").

### Scale

- **US architectural dimensions read correctly**: `4'-6"` is 54 inches (was 42), and `4'-6 1/2"` is 54.5.

### AP Labeler

- **A second project starts from the saved pattern**, not the previous project's site text.
- **A project opened while the page is still starting keeps its own scheme.** The saved pattern used to arrive afterwards and replace the names adopted from the project.
- **Adopting a project's own scheme keeps its floor tokens.** `F1`, `L2` and similar were rewritten to `01`, `02` on every AP.
- **Manual (click order) numbers in click order across floors**, and **Next** shows the number the next click gets.
- **The counter start box takes "101"** without losing focus, and a start of 0 is kept.
- **Row and column spacing uses each floor's own size**, so the open floor tab no longer changes the names.
- **The downloaded .esx is compressed** again (it was about 11 times larger).

### Capacity, Settings and Setup

- **Saving a capacity template never overwrites another.** A taken name, a second Duplicate, a rename onto another template or a capitals-only rename is refused with the name of the template already there, and Duplicate proposes a free name.
- **Settings → Default subfolders, and the same Setup step, take effect.** A new site folder (Squirrel's **Create Folder**, Cloud Manager's new local folder) gets exactly the listed subfolders in that order, including added ones. Organize still sorts into a built-in left off the list.
- **Applying a template keeps the requirement on an area already drawn.**
- **"Re-run Setup Wizard", "Open Report" and "← Home" work from the Settings panel.** They showed a refused page.
- **Importing a settings export keeps "Last exported".** The update check no longer fails when GitHub returns no release.

## Verified

- Each fix has a test that runs the real code (the server functions, the page's own handlers in Node, or the page in Firefox) against invented projects and folders, and fails on 2.207.1.
- AP Installation printed to PDF in Firefox from an invented 71-AP, two-floor project: all-omni floors carry Mount, Height and Ant., text 7.5–9pt, no overlaps, nothing within 18pt of the edge, and 69 of 69 long AP names in full.
- The full test suite passes.
