# Cloud Manager reads at arm's length, and the Sync plan fits its window

Suite **2.206.0**: Cloud Manager **4.79.0**.

## What changed

### Cloud Manager

- **Larger text throughout the list.** Project and file names are 15 pixels (were 12.5); the sentence under a row that needs something, the buttons in it, the counts across the top, the **Owner** buttons and every item in a row's **⋯** menu are 14; dates, type tags such as **Design**, the match badge such as **Same project**, and the A–Z letters are 13 (were 10.5–12). The toolbar buttons - **⇅ Sync everything**, **Select**, **Show only mine** - are 14. Nothing else about the list changes: same rows, same order, same buttons.
- **The ⇅ Sync everything plan fits its window.** The plan opened in a dialog about 430 pixels wide on a 1366-pixel screen, so column headings and file names broke mid-word ("What differs" over three lines). The dialog now widens to about 1040 pixels (or 94% of a narrower window) when it shows the plan, the tables read at 14 pixels, and **Cancel** and **Sync N** stay at the bottom of the dialog while the plan scrolls. Other confirmations keep their usual size.
- The plan no longer says "All 1 listed above — scroll the box for the rest"; it mentions scrolling only when the list is long enough to need it.

## Verified

- In headless Firefox with an invented account at 1366×1000: every project name is at least 15 pixels, every date at least 13, and every row explanation at least 14. With the change removed, all three fail.
- In headless Firefox at 1366×768 and 1366×1000, **⇅ Sync everything** opens a plan at least 900 pixels wide, every column heading on one line, and the **Sync** button inside the window. With the change removed, the dialog is narrower and the headings wrap.
- Each view looked at in headless Firefox at 1366×1080 and 2519×1279 with an invented account: Flat, Tree, the Sync plan.
- The full test suite passes.

- `web/assets/wd-tools.css`: the readable sizes for Cloud Manager; the Sync plan's width, type size and pinned buttons
- `web/assets/js/cloud.js`: the plan's "scroll" sentence only when the list is long
