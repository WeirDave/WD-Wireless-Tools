v1.30.1 taught Squirrel's **+ Create Project Folder** to top up subfolders when the site folder already existed on disk. But you still had to *type* the existing folder's name exactly — copy-paste from Explorer, or squint at what's already in the root. Awkward when the whole point was to skip a trip to Explorer.

**New: existing-folder picker.** The **Folder name** field is now an autocomplete. Click the input (or start typing) and a dropdown lists every real site folder currently in your root — no more retyping. Type a name that isn't there yet and it just accepts the new name.

**New: live status pill.** A small pill under the field tells you which mode Squirrel is about to run:

- Green **✚ New folder — will be created** — the name doesn't match anything in the root.
- Amber **↯ Existing folder — will add missing subfolders only** — the name matches something already there, so Squirrel will only mkdir the subs that aren't in it yet. Case-insensitive match, so `acmecorp` finds `AcmeCorp` too.

No mode toggle, no extra clicks — one input covers both flows and the pill just tells you which one is active.

Suite `v1.31.1 → v1.31.2`. Squirrel `v1.22 → v1.23`.
