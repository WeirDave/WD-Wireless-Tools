# WD Wireless Tools v2.0.0

This is the first clean public release of WD Wireless Tools: a local, browser-based suite for common Ekahau workflows.

## Included tools

- Cloud Manager for comparing and managing Ekahau Cloud and local project files.
- Quick Walls for editing wall types and applying reusable templates.
- Squirrel for organizing project folders and related files.
- Scale for architectural and metric measurement conversion.
- Report for producing installation, summary, audit, interference, bill-of-materials, antenna-aiming, and advisory coverage documents.
- Eight visually distinct Report template cards for faster template recognition.

## Privacy and security

- Ekahau project parsing for Quick Walls and Report happens locally in the browser.
- The application includes no telemetry.
- Saved Cloud sessions are encrypted, with the key stored in the operating system credential vault.
- Public examples and release assets use fictional, non-client data.
- HTML and inline JavaScript output paths use context-appropriate escaping for project-controlled values.

## Compatibility

- Windows and macOS.
- Python 3.10 or newer for the complete desktop suite.
- Quick Walls, Scale, and Report can run without the Python backend when hosted.

See the README for installation, first-run setup, privacy details, and troubleshooting.
