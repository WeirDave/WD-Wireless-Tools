# Corners on one scale across every tool, and the stylesheet's design tokens

Suite **2.198.0**. No tool's own version changes; the change is to the suite's shared stylesheet.

## What changed

### All tools

- **Rounded corners now follow one scale everywhere**: 4, 6, 8 and 12 pixels, plus fully rounded pills. Fifteen different corner sizes had accumulated, from 3 to 22 pixels, so neighbouring cards, buttons and inputs were rounded slightly differently. Hairline bars of 1 and 2 pixels keep their own rounding.
- **Colours that were written out by hand now use the suite's named colours** wherever the value was already identical: 57 places across the stylesheet. Nothing changes on screen.
- **The type and spacing scales are defined**: six text sizes (11, 12, 13, 15, 18 and 22 pixels) and spacing on a 4-pixel grid. Later releases in the visual refresh move each tool onto them.

## Verified

- Home, Settings, Quick Walls, Report, Capacity, Prep, PlanTrim, AP Labeler, Scale and Squirrel were captured in headless Chromium in the dark and light themes, before and after, and compared pixel by pixel. The only differences are at corners; every page otherwise renders identically.
- A new check fails on any rounded corner off the scale, and on any increase in the number of written-out colours or distinct text sizes, so the stylesheet cannot drift back.
- The full test suite passes.

## Files changed

- `web/assets/wd-tools.css`: corner, type and spacing tokens; 321 corners and 57 colours moved onto tokens
- `tests/test_the_stylesheet_stays_on_its_scale.py`: new
