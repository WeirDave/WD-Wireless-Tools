# Quick Walls adds Tree Canopy and Shrubbery attenuation areas for outdoor spaces

Suite **2.217.0**: Quick Walls **7.75.0**. Every other tool is unchanged.

## What changed

### Quick Walls

- **Outdoor attenuation area presets.** Quick Walls has a new **"Attenuation Areas"** tab beside **"Wall Types"**. It lists two presets, each with its edges and its loss at 2.4 / 5 / 6 GHz, and below them the area types the project already has, in feet and dB per foot:
  - **Tree Canopy**: lower edge 9 ft, upper edge 35 ft, 1 / 1.3 / 1.5 dB per foot.
  - **Shrubbery, Low Planting**: lower edge 0 ft, upper edge 4 ft, 1.2 / 1.6 / 1.8 dB per foot.
- **"+ Add Tree Canopy & Shrubbery"** adds both to the project's attenuation area list, so they can be drawn over outdoor spaces in Ekahau. Feet and dB per foot are converted to metres and dB per metre. A type with the same name is updated in place and keeps its id; areas already drawn are not changed; a second press changes nothing. **"Save the *.esx"** writes them, and the footer names the attenuation area types it will write.
- The button is greyed, with the reason beside it, when the project has no attenuation area type to copy the file layout from. Add any area type in Ekahau once and open the project again.

## Verified

- The presets are added with the converted edges and per-band values, existing fields on the copied layout survive, existing types are untouched, and a repeat run changes nothing. Breaking the unit conversion, or Save skipping the file, turns the tests red.
- The suite passes.
