# Prep and Capacity: the active area-drawing button is now highlighted

Suite **2.243.1**. Report **2.76.0**. Prep **2.9.1**. Capacity **1.12.2**. Other tools are unchanged.

## What changed

### Prep and Capacity: drawing the requirement area

- **The drawing tool in use is now shown on its button.** In Prep (Requirement areas) and in Capacity, **Draw a rectangle** and **Draw a shape** previously looked the same whether or not a tool was active. The active button now fills solid pink, the colour the area is drawn in on the plan, with bold text and a ring. Switching to the other button moves the highlight; pressing the highlighted button again, finishing the outline, or pressing Esc returns it to normal. The sentence under the buttons still describes the active tool.

### Suite: stylesheet

- A shared white-on-fill colour is now one setting (`--on-accent`) in place of repeated literals on the solid green, amber, rose, teal and purple buttons. Their appearance is unchanged.

### Report

- **Floors to include and APs to include now come first on the Configure step.** The order is the description of the report, then **Floors to include**, then **APs to include**, then **Your details**, **Cover page** and the report's own options. What the report covers is settled before the options that depend on it.
- **Configure grid… lists only the included floors.** The **Floor plan** dropdown holds the floors that are in, and the dialog opens on the first of them. **Apply to All Floors** copies the crop and combined sections to the included floors only; a floor that is left out keeps what was set on it, so ticking it again finds it unchanged. The confirmation names how many floors it reached.
- **Set up column grid… lists only the included floors.** The button on the **Set up column grid…** row counts the included floors ("1 of 2 floors"), not every floor in the project.
- **The grid buttons follow the floor choice at once.** Ticking or unticking a floor updates the "(cropped)" and "(combined)" markers on **Configure grid…** and the count on **Set up column grid…** without leaving the step.
- **The Grid column no longer appears for floors that are out.** The column grid reference column is offered only when an included floor has a column grid set up.
- **No floors included.** With every floor cleared, **Configure grid…** and **Set up column grid…** say that no floors are included instead of opening.
- **Spacing between the cards on the Configure step.** Full-width cards are separated by 16 px.

## Verified

- The real button markup is rendered in the browser pane; the pressed button resolves to solid pink with white text and the idle buttons are unchanged.
- The existing tests that press each button through its real handler and assert the pressed state pass.
- The full suite passes.
