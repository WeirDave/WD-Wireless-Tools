# Report: measured radios follow the chosen floors

Suite **2.242.1**. Report **2.75.1**. Other tools are unchanged.

## What changed

### Report

- **Site Summary Sheet: the "Measured radios" count follows the floors.** With floors left out in **Floors to include**, the count covers only the radios of access points on the floors that remain, and the tile is omitted when none remain. In 2.75.0 the count dropped to nothing whenever any floor was left out.

## Verified

- A new test uses the structure survey projects actually carry (a measured radio names its access point and a list of measurements) and checks the count for every floor in, one floor out, and only a floor with none. It fails against the previous behaviour.
- Full test suite passes.
