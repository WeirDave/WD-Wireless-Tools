# Report: section grid cells can be combined, landscape section sheets fill the page, and the cover turns with the report

Suite **2.181.0** ships **Report 2.66.0**. The Report page shows the Report number, not the suite number.

## What changed

### Report → Configure grid

- **Neighbouring grid cells can now be combined into one section.** A combined section prints as one sheet, with one box on the Key Plan and one entry in the section index, while the rest of the grid stays divided. It is meant for an open area the grid would otherwise cut into sheets of empty floor. For example, on an L-shaped building with a 3×2 grid, A1 + A2 can become section **A** and B1 + B2 section **B** for the warehouse leg, while C1 and C2 stay separate for the office.
- **Where it is:** Report → AP Placement Map or AP Installation, options panel in the **Configure** step. Turn on **Split large floor plans into zoomed sections**, click **Configure grid…**, then use the **Combine cells** button in the row under **Columns** and **Rows**.
- **How to use it:** click **Combine cells**. The crop box stops moving and clicks on the plan pick cells, which are shaded pink. Pick the cells to join and click **Combine selected**. To undo, click a combined section, which picks all of it, then click **Split**. Click **Finish combining** to go back to moving the crop box. The text beside the buttons names the section that will be made, or explains why **Combine selected** is not available: fewer than two cells picked, cells that do not make a rectangle, or a selection that cuts through an existing combined section.
- **Default:** no cells are combined, and reports are unchanged until cells are combined.
- **Naming:** a combined section that covers a whole column from top to bottom takes that column's letter (**A**). Two or more whole columns are named **A–B**. Any other combined section is named by its corners (**A1–B2**). The sheet titles, the section index, the Key Plan and the match line labels all use the combined name.
- **Match lines:** an edge that meets more than one section now names every section it meets, for example "MATCH LINE — SECTIONS C1, C2". A dashed line is drawn along each part of the edge where the drawing continues.
- **Floors and grid size:** combined sections are set for each floor separately. **Apply to All Floors** copies them to every floor along with the crop. Changing the number of columns or rows, or resizing the crop box in a way that changes them, clears combined sections because they no longer cover the same area, and a message says so.
- **Not saved:** like the other grid settings, combined sections last until the page is reloaded or another report is picked.
- When cells are combined, the **Configure grid…** button in the options panel shows **(combined)**, the cell count in the dialog reads for example "6 cells in 4 sections", and the note above the printed index says how many sections were combined.

### Report → page orientation

- **The cover page now turns with the rest of the report.** Before this release it always printed portrait, even after **Match all pages**. It now has the same **Page: Auto / Portrait / Landscape** control above it as every other page. **Default:** Auto, which gives the cover the orientation most of the report's sheets print in. A floor split into eight section sheets counts as eight sheets, and a tie follows the page printed straight after the cover. **Match all pages** now includes the cover.
- **Landscape section sheets now fill the page.** On a floor split into sections and set to Landscape, each section map was still sized for a portrait sheet: 6.9in wide in the middle of an 11in sheet. Section maps and the section index are now sized for the sheet they print on. A wide section that printed 6.90in wide prints 9.46in wide. Portrait sections are unchanged.
- **Auto now turns a floor split into sections when that prints its maps meaningfully larger**, by the same rule a whole-floor map already used: landscape only when the maps print at least 15% larger that way round. Before this release, Auto always left a sectioned floor portrait. The control is **Page** above each floor in the Review & Print step. Setting it to **Portrait** keeps the old behaviour for that floor.
- **Tall buildings: the section header and map stay on one sheet.** The Key Plan thumbnail on each section sheet is now at most 1.1in tall. On a tall plan it could reach about 2in and push the map onto the next sheet, leaving the section header alone on a sheet of its own.

## Verified

- A 3×2 grid with A1 + A2 and B1 + B2 combined prints four sheets titled A, B, C1 and C2. Sheet A is cropped to the whole column and carries the APs from both cells. The index and the Key Plan are labelled A, B, C1 and C2.
- Section B's right-hand match line names C1 and C2 and is drawn along each half of the edge. C1's left-hand match line names B and runs only along C1's own height.
- With no cells combined, the six sheets are unchanged. Combined sections saved for a different number of columns or rows are ignored.
- **Combine selected** refuses a single cell, a set of cells that does not form a rectangle, a selection that cuts through a combined section, and cells that are already one section. Each refusal shows its reason. **Split** removes only the combined section that was picked.
- In Chromium, clicking cells with the mouse, **Combine selected** and **Split** produced the expected sections and labels. The result was still there after **Done** and reopening the dialog, and the page raised no errors. Firefox, Chrome and Edge are covered by a browser test that runs where those browsers are installed.
- The tests fail if the renderer ignores combined sections, or if a match line is drawn along the whole edge instead of only the part that meets its neighbour.
- The AP Placement Map was printed to PDF through Chromium on a wide, a squarish and a tall floor plan, each with and without sections, on Auto and with **Match all pages** set to landscape. Page sizes, map sizes and positions were read back from the PDF:
  - the cover prints landscape whenever most sheets do, and portrait otherwise;
  - landscape section maps print 9.46in wide on a wide section, up from 6.90in;
  - on every sheet, the map and its key line stay above the bottom margin;
  - the tall plan's sections print on 7 sheets instead of 8, because the header no longer sits alone on a sheet;
  - portrait sections on the wide and squarish plans are the same size as before.
- The tests fail if the cover loses its page key, if the orientation pass stops turning the cover, if landscape sections are sized for portrait, if the Key Plan thumbnail is not capped, or if Auto no longer turns a sectioned floor.
