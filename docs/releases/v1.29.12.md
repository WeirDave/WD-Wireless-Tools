*"Report is in the folder but no AP directions are shown."* — Dave, on a directional-AP project.

The Directional Antenna Installation and AP Aim reports were dropping the direction cones and aim ticks for any AP whose radio had `antennaMounting: CEILING` — even when the antenna itself was directional. That's the wrong signal: patch-in-ceiling AP designs mount in the ceiling but still have a defined azimuth. On this project all 38 directional APs came back as blank pink dots.

Fix: decide directionality from the antenna type's `directional` flag (with a name-based `/omni/` fallback for older files), not from mount type. Same fix runs through the omni-only classifier that gates the aim report's AP list.

Suite `v1.29.11 → v1.29.12`, WD Report `v2.12 → v2.13`.

## Files changed

- `web/assets/js/report.js` — new `antennaIsDirectional()` / `radioIsDirectional()` helpers; `renderAntennaOverview` cone marks and `renderAimMiniMap` aim ticks now consult the antenna type instead of `mount !== 'CEILING'`; `apIsOmniOnly` uses the same predicate.
- `web/report.html`, `web/assets/versions.json` — version bumps.
