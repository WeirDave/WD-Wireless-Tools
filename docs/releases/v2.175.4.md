# Squirrel's home page fits on one screen, with all five tools in one row

Suite **2.175.4** ships **Squirrel 1.27.7**. The Squirrel page header shows the Squirrel number, not the suite number.

## What changed

### Squirrel (the page at `/squirrel`, before a folder is picked)

- **The five tool cards (Organize Files, Create Project Folder, Extract Floorplans, Rename and Acorn Notes) now share one row** whenever the window is at least 1080 pixels wide. The row used to be capped at three cards, so **Rename** and **Acorn Notes** always wrapped to a second row, and on a laptop screen they sat below the bottom of the window with empty space on either side.
- **On a short window (860 pixels tall or less) the squirrel icon, heading and spacing above the cards are smaller**, so the whole page fits without scrolling at common laptop sizes such as 1280×720 and 1366×768.
- **Windows narrower than 1080 pixels** keep the previous layout: the cards wrap onto more rows and the page scrolls.
- Nothing needs to be turned on, and no other tool's layout changed.

## Verified

- The page was measured in a browser at 1280×720, 1366×768, 1536×864, 1920×1080 and 2560×1440. At every size all five cards were on one row, the last card ended above the bottom of the window, and nothing spilled sideways, including with the "Last:" folder path showing under **Organize Files**. At 900 pixels wide the cards wrap onto more rows as before.
- A new automated test takes the same measurements in Chrome, Edge and Firefox wherever they are installed. With the change removed, the one-row and fits-the-screen checks fail.

## Files changed

- `web/assets/wd-tools.css`: layout rules for Squirrel's home page only
- `tests/test_squirrel_home_fits_the_screen.py`: new browser test
- `web/assets/versions.json`, `README.md`: version numbers
