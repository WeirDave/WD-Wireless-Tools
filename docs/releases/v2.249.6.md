# Cloud Manager: a local-only file shows one Upload button instead of two

Suite **2.249.6**, Cloud Manager **4.97.2**. The other tools are unchanged.

## What changed

### Cloud Manager

- **A file that exists only on disk has one Upload button.** Previously the empty cloud side of the row held a faint "Upload" button and the line underneath held a second, blue "Upload". Only the blue one remains, in the line underneath, beside "Link to a cloud project…". A project that exists only in the cloud already worked this way, so both kinds of unpaired row now behave the same.
- **A pair matched on name alone explains its "Download over local" button.** The sentence under such a pair now reads "Matched by name only — nothing has proved these are the same file. Download over local replaces your file with the cloud copy, so the two become identical." The button's behaviour is unchanged.

## Verified

- The full test suite passes.
- The upload from a local-only file inside a site folder is rendered once and uploads into that site.
