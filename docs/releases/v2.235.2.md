# Cloud Manager: larger search clear button, a matching explanation that fits a laptop, and a settings gear that reads as a gear

Suite **2.235.2**, Cloud Manager **4.90.2**. Every other tool is unchanged.

## What changed

### Cloud Manager: toolbar

- **The × beside the search box is larger.** It was a small unstyled button; it is now a 30 px square with a bold cross, in both themes, and still empties the box.
- **The settings gear is drawn as a gear.** It was a text character that several systems rendered as a small dot inside the round button. The gear at the right end of the toolbar is now an icon with eight teeth in the same 28 px round button, in the dark and light themes.

### Cloud Manager: the ⓘ explanation

- **"How matching works" opens wide and does not scroll on a 1366 × 768 screen.** The ⓘ button beside **Select** previously opened a narrow strip of text with a scrollbar. The dialog is now up to 1280 px wide and reads in three columns, with the title and the **Got it** button always visible. On a window too short to hold it, only the text area scrolls. Narrower windows use two columns, then one.

## Verified

- Cloud Manager is opened at 1366 × 768 in Chrome, Edge and Firefox in both themes: the × is at least 28 px square and empties the search box when clicked, the gear is a drawn icon in a 28 px button, and the explanation is over 900 px wide with no scrolling in the dialog. With each change removed, the matching test fails in all three browsers.
