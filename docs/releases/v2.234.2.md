# Quick Walls: Visual Swap also folds "(Copy)" wall types into the original

Suite **2.234.2**, Quick Walls **7.78.2**. Every other tool is unchanged. This release also carries the Visual Swap change of 2.234.1, which was not published separately.

## What changed

### Quick Walls: Visual Swap

- **"(Copy)" and "(Copy)(Copy)" wall types are listed under the original's name.** A type named "Window, Thick(Copy)" or "Window, Thick(Copy)(Copy)" no longer appears as a line of its own. This applies to **Change checked to** under **Selected**, to **From** and **To** under **Quick swap by type**, to **Wall types on this floor**, and to the **Selected** groups. The suffix is recognised with or without a space before it, so copies made with Clone in Quick Walls and copies made in Ekahau are both covered, and "(Copy 2)" is covered as well.
- **Choosing the name covers every copy.** **Swap all** with **From** set to "Window, Thick" moves the walls drawn with the original and with each copy. A swap to the name lands on the original. Undo returns each wall to the type it was drawn with.
- **Copies with no original in the project show the name without the suffix.** If only "Shelf(Copy)" and "Shelf(Copy)(Copy)" exist, the lists show "Shelf" once.
- **A name that only contains the word "Copy" elsewhere is left alone.** For example, "Copy Station Wall" stays as it is.
- **Wall types in the project are not edited or removed.** Only the lists and the swap treat copies as one.

### Carried from 2.234.1

- Wall types with the same name (ignoring case and spacing) are listed once in the same places, and the swap covers every copy.

## Verified

- A project containing same-name copies, "(Copy)" and "(Copy)(Copy)" types with and without an original, and a name that only contains the word "Copy" is opened in the real page in Chrome, Edge and Firefox. Every dropdown is read back, the legend and **Selected** groups are counted, and the real **Swap all** and Undo handlers are run.
- With the change removed, these checks fail.
