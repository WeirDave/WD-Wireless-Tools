# A status pill in every page header shows the update state and the Ekahau Cloud sign-in

Suite **2.247.0**. Cloud Manager stays at 4.93.0.

## What changed

### Every page

- **A status pill now sits in the top right of every page header, beside the Dark / Light toggle.** It is always visible. It reads "Up to date" while the install is current and turns amber with "Update" when a release is waiting. Hovering it states what is available and whether Ekahau Cloud is signed in. Clicking it opens **About & Updates**.
- **The pill also shows the Ekahau Cloud sign-in.** A cloud icon at the right of the pill is solid green while signed in, solid grey for a saved sign-in that has not been used yet this session, an outline when there is no sign-in, and amber when Ekahau has stopped accepting the sign-in. An expired sign-in turns the pill amber and changes its label to "Sign in", or "Update · Sign in" when an update is also waiting.
- **Pages with no theme toggle, such as the User Guide, get one pill pinned to the top right.** The first-run Setup page has none.
- **Cloud Manager's sign-in screen still has no header**, so the pill appears once signed in.

### About & Updates (Menu, then "About & Updates", or click the pill)

- **A new "Ekahau Cloud" card sits under the version, beside the "Updates" card.** It shows one of four states: "Signed in as" the account, "Saved sign-in", "Sign-in expired" or "Not signed in". The card is amber while the sign-in has expired.
- **"Log in to Ekahau Cloud" signs back in from any page.** It opens Ekahau Cloud in the default browser and then watches for the new sign-in, checking every two seconds and again whenever the window regains focus. The card changes to "Signed in" and the pill clears when the sign-in is found. "Cancel" stops the wait, and so does closing About. The wait ends after ten minutes. After twelve seconds without a result the card says what was found in each browser.
- **"Check now" asks Ekahau whether the current sign-in still works.** It is the only control on the card, apart from the sign-in wait, that contacts Ekahau. A network that is down is reported as such and is not treated as an expired sign-in.
- **The pill and About read the sign-in state from the tool's own server and never contact Ekahau Cloud on their own.** This holds on every page load, on the 30-second refresh and when About opens. Cloud Manager contacts Ekahau only when its own tools are used or when "Check now" or "Log in to Ekahau Cloud" is pressed, as before.
- **An expired sign-in is recognised as soon as Cloud Manager finds it**, from a rejected listing, a rejected download or a rejected saved sign-in at start-up. A deliberate "Forget login" is not shown as expired.

## Verified

- A browser test in Chrome, Edge and Firefox loads twelve tool pages and the User Guide. It checks that the pill sits against the theme toggle on the same row, that the header stays at the top of the window, that the page does not scroll sideways, and that the old banner and badge are gone.
- The same test checks the label, colour and cloud icon for each sign-in state, with and without an update. It clicks the pill and checks that About opens with the right card state and buttons.
- It drives "Log in to Ekahau Cloud" through to the pill clearing, and checks that Cancel and closing About stop the wait, that "Check now" asks exactly once, and that opening About asks Ekahau nothing.
- Server tests cover the four sign-in states and each way a sign-in becomes expired or is cleared. They check that the state call makes no network request, and the route is exercised through the real dispatcher.
- The status labels in the pill and the new card clear 4.5:1 contrast, and the cloud icon and dots clear 3:1, in the dark and light themes.
- The full suite passes.
