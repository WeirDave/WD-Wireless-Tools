# Prep, Capacity and PlanTrim headers are coloured like the other tools

Suite **2.175.9** ships **Prep 1.10.4, Capacity 1.4.5 and PlanTrim 1.19.4**. Each tool's page header shows that tool's own number, not the suite number.

## What changed

### Prep, Capacity and PlanTrim: the header bar across the top of the page

- **The header bar is now tinted with the tool's colour, and the tool's name in it is shown in that colour**: lime for Prep, azure for Capacity, teal for PlanTrim. These are the same colours as the tool's tile on the Home page and its drop box since 2.175.8. The bar used to be the plain default, a grey bar in the light theme and a near-black one in the dark theme, with the tool's name in plain white or black. Quick Walls, Report and AP Labeler were already coloured this way.
- The colour applies both on the opening screen and on the header shown once an `.esx` is open, in both the dark and light themes.
- In the light theme Prep's name uses a darker lime, and in the dark theme Capacity's name uses a lighter azure, so both stay readable against their bar.
- Nothing needs to be turned on.

## Verified

- All six file-based tools were measured in a browser in both themes, before and after a file is opened. Every header bar is tinted, every tool name is in its tool's colour, and no two tools share a colour.
- A new automated test takes the same measurements in Chrome, Edge and Firefox wherever they are installed. It fails for Prep, Capacity and PlanTrim on the previous stylesheet.

## Files changed

- `web/assets/wd-tools.css`: header colours for Prep, Capacity and PlanTrim, taken from the same colour setting as their drop boxes
- `tests/test_every_tool_header_carries_its_colour.py`: new browser test
- `web/assets/versions.json`, `README.md`: version numbers
