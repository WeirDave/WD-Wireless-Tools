# Cloud Manager's site line says which filter is hiding files

Suite **2.249.2**, Cloud Manager **4.97.1**. The other tools are unchanged.

## What changed

### Cloud Manager

- **The file count on a site's line now names what is hiding the rest.** When a site holds more files than the list shows, the line used to read only "2 of 7 files". It now adds the cause:
  - **"5 from other owners hidden"** when the **Owner** toggle in the toolbar is on **Mine** and the site holds projects owned by someone else.
  - **"2 yours hidden"** when the toggle is on **Others**.
  - **"N hidden by filter"** for files hidden by the status filter (Needs decision, Out of sync and the other chips).
  - Both can appear together, and the figures add up to the number of files in the site.
- **The hover text on that line explains it in full**, for example that five files are hidden by the Owner filter (Mine) and that choosing **All** in the toolbar shows them.
- **A site with nothing hidden is unchanged**: it still reads "N files" with no filter wording.

## Verified

- The full suite passes. A new test renders the real site line for a site with two own projects and five owned by others, and checks the wording on Mine, Others and All, with a status filter alone, and with both filters together. It fails without the change.
