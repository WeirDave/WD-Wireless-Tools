# Settings: the sections are cards, like the tools on Home

Suite **2.246.1**. Tool versions are unchanged.

## What changed

### Settings (Menu → Suite Settings)

- **Each section is a card in its tool's colour, the same kind used for the tools on Home.** A card has a 2.5px outline in the tool's colour, the tool's icon, the section name and one line saying what is in it, for example "Merge rule, view, refresh, login" under Cloud Manager. They replace the row of folder-style tabs.
- **On a wide window the cards stack down the left and stay in view while the section scrolls.** If the window is shorter than the list, the list scrolls by itself.
- **On a narrow window, or in the panel a tool opens Settings in, the cards form a grid across the top.** Below 640px wide each card shows the icon and name only.
- **The open section's card is tinted.** The section's own name is no longer printed again as a heading under the cards.
- **General, Subfolder Structure and Backup & restore have a neutral outline and the suite icon**, since they belong to no single tool.
- **One section is shown at a time at every width.** On a narrow window the sections used to fold open and shut in place, which gave the page two ways to move around. The cards are now the only way, and the open section can no longer be folded away.
- **Card names are the tool's colour mixed toward the page's text colour**, so every name is readable on both themes. Home's tile names use the brand colour as it is.

## Verified

- The page was checked in the browser's built-in Chromium engine, in dark and light, at 1280px, 900px and 540px wide. The Firefox, Chrome and Edge CI jobs run on the push.
- Tests cover each card's line and icon, the cards built from the sections, the name colour against the card in both themes and when a card is open, and one distinct colour for each tool section.
- The full suite passes apart from one Edge-only PlanTrim test that fails when the browsers run in parallel and passes when run alone.
