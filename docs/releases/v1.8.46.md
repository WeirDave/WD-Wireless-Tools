Two Move-to-Site follow-ups from v1.8.45 usability: the native `<select>` popup was covering the source card when opened near the bottom of the modal (so you'd lose sight of which file you were routing), and a long site list made scrolling for a specific site tedious. Fixed both:

- **Filename in the modal title** — `Move "sample-project.esx" to Site` instead of just `Move to Site`, so the file identity stays visible even if a dropdown covers the source card below.
- **Searchable typeahead** replaces the native `<select>` — bounded, scrollable list rendered inside the modal (no more browser popup hijacking the layout), typing filters as you go, arrow keys navigate, `+ Create new site: "<query>"` appears inline when the typed text doesn't match anything.

Suite `v1.8.45 → v1.8.46`. WD Cloud Manager `v3.48 → v3.49`.

## What changed

### The typeahead

Replaces the `<select>` dropdown in both the global picker and each bulk-mode per-row picker. Every picker now looks like:

```
┌──────────────────────────────────────────────────────────┬───┐
│  Type to search sites, or pick from the list…            │ × │
└──────────────────────────────────────────────────────────┴───┘
    ┌─────────────────────────────────────────────────────┐
    │  SITE2 - 500 Example Place NW, Fairview, GA 30000     │  ← 220px
    │  SITE-001 - 100 Example Ave, Springfield, CA 90001     │    max
    │  SITE-001 - B2 - 200 Example Dr, Springfield, CA 90002   │    height,
    │  SITE-001 - 300 Example Ave, Springfield, CA 90002  local  │    scrollbar
    │  … 38 more                                           │    inside
    └─────────────────────────────────────────────────────┘
```

Key behavior:

- **Type to filter** — substring match against every site name, or the same fuzzy matcher used for auto-suggest (so "harbor" surfaces "SITE-001 - 100 Example Ave, Springfield" even though it's a partial address match).
- **Bounded height** — `max-height: 220px` with `overflow-y: auto`. Long site lists behave like any normal scrolling dropdown.
- **Rendered inside the modal** — `position: absolute` inside a `.modal.file-op` container, `z-index: 200`. No native browser popup that pops above or below unpredictably.
- **Keyboard navigation** — Arrow-Up / Arrow-Down navigates highlighted item, Enter picks, Escape closes.
- **Inline "+ Create new site"** — when the typed text doesn't match any existing site, the last item becomes `+ Create new site: "<what you typed>"`. Click it to create — no separate button, no separate flow. Uses the query text as the new site name.
- **Clear button** — the small × on the right resets the picker for that row.
- **Auto-match badge preserved** — the AUTO tag stays until you pick something, then disappears on the same row.

### Filename in modal title

Single-item mode only — bulk mode already puts each row's picker adjacent to its own filename, so the title just says "Move 3 items to Site." For a single move:

- Before: `Move to Site` (source name only in the body)
- After: `Move "sample-project.esx" to Site`

Belt-and-suspenders: even if a picker covers everything else in the modal, the title at the very top still tells you which file you're routing.
