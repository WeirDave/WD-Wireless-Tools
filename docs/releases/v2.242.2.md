# Report: pages are no longer cut off at the right when saving to PDF from Firefox

Suite **2.242.2**. Report **2.75.2**. Other tools are unchanged.

## What changed

### Report

- **A report saved to PDF from Firefox 158 or later is no longer cut off at the right-hand side.** Firefox 158 and later writes every sheet on the paper the print dialog names and ignores the page size a report asks for. A page laid out landscape therefore landed on a portrait sheet and lost everything past the sheet edge. This affected the AP Placement Map and every other report whose pages were turned landscape, including pages turned landscape by **Auto**. In these versions the report now asks for no page size of its own and is laid out to the width of the sheet the print dialog chose.
- **In Firefox 158 and later the whole report is one orientation.** Choosing **Portrait** or **Landscape** in the *Page* control above any sheet on the Review step applies to every page, and **Auto** resolves to portrait. Set **Orientation** in the print dialog to match. The Print step says so when it applies.
- **Chrome and Edge are unchanged.** Each page still prints on the sheet it asks for, and portrait and landscape pages can be mixed in one PDF.
- The tooltip on **Match all pages** no longer says mixing orientations is verified in Firefox.

## Verified

- The real AP Placement Map was printed through Firefox 159's own Save to PDF path with the print dialog set to Portrait and to Landscape, with nothing chosen and with Landscape chosen. Every sheet came out on the dialog's paper and the heading rule on each sheet ended inside the right margin. Before the change the same print put landscape-laid-out pages on portrait Letter with the rule running 150pt past the sheet edge.
- Chrome, Edge and Firefox print the report with every page turned landscape and the sheets stay on the paper the print options name. Each of these checks fails when the new print rules are removed.
- Full test suite passes.
