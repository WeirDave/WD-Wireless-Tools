The Cloud Manager dashboard cards had a small but persistent visual quirk: the left edge of every non-active card looked chopped off. Turns out it was a mitered-border artifact that had been sitting there since the dash-cards were first introduced. Fixed.

Suite `v1.24.0 → v1.24.1`. Cloud Manager `v4.12.0 → v4.12.1`.

## What was wrong

`.dash-card` set `border: 1px solid var(--dc)` on the top, right, and bottom sides and `border-left: 3px solid transparent` on the left — the intent being that when a card became `.active`, the transparent left border could take a chunky colored value to act as a "you're filtering by this" indicator.

The problem: when adjacent borders have different widths, CSS miters the corner diagonally. A 1px colored top border meeting a 3px transparent left border produces a diagonal cut at the top-left corner where the top-border tapers to nothing over the invisible 3px stretch — and the same at the bottom-left corner. On the pill-shaped cards, this reads as "the front of the button is sliced off." Once you see it you can't unsee it.

## The fix

Uniform 1px border on all four sides, and move the chunky colored left accent for the active state into an inset box-shadow so it doesn't need to expand the border box:

```css
.dash-card {
  border: 1px solid var(--dc);           /* was: border-left: 3px solid transparent */
  padding: 3px 10px 3px 12px;            /* +2px left to visually replace the 3px accent when inactive */
}

.dash-card.active {
  background: var(--dc-active);
  box-shadow: inset 3px 0 0 var(--dc);   /* was: border-left-color: var(--dc) */
}
```

Because `box-shadow` paints inside the element without changing border widths, all four corners of the card stay square-mitered against a uniform 1px outline. The active state's colored left accent now sits inside the padding, so content placement doesn't shift when a card gains or loses `.active`.

## User-visible behavior change

- Every card in the Cloud Manager dashboard (ALL, CLOUD ONLY, LOCAL ONLY, MISMATCHES, ORPHANS, EXTERNAL, plus the type / duplicate filter cards) now has a clean rectangular outline with no diagonal cut at the front.
- The colored left-edge indicator for the currently-active filter still shows, just rendered as an inset shadow instead of a wider border.
- No JS changes; existing filter logic and click handling unchanged.

## Verification

1. Open `/cloud`. The Files-tab dashboard cards should all show a uniform 1px border on every side. The left edge of each pill should look identical to the right edge.
2. Click any card. It should light up with a matching-colored 3px accent stripe on its inside-left, and the fill turns into that color's low-alpha tint.
3. Click another card. The accent moves. Content within the card doesn't shift horizontally (because the shadow lives in the padding).
