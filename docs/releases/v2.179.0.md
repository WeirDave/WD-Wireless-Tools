# Capacity: a headcount for each floor

Suite **2.179.0** ships **Capacity 1.5.0**. The Capacity page shows the Capacity number, not the suite number.

## What changed

### Capacity → Apply a template

- **Each floor now takes its own headcount.** Before this release one number was applied to every floor, so a three-storey building for 600 people was written with 600 people's devices on each storey, 1,800 in total. Each floor can now be sized for the people who are actually on it.
- **Where it is:** Capacity, step **3 — Apply a template to this project**. Every floor in the preview has a **People on this floor** box under its description.
- **Default:** blank. A blank box uses the number in **Each floor is for** at the top of step 3, which is shown greyed inside the box. This field was labelled **This building is for** in earlier releases; it now says **Each floor is for** because that is what it has always done.
- Type a number to size that floor for that many people. Type **0** to leave the floor alone: nothing is written to it, and the preview marks it "skip - no people on this floor".
- The preview updates when you leave the box. Each floor shows its own device count, and the line under the floors totals the people and devices across every floor that will be written. The result after **Apply and download** reports the same totals.
- Per-floor numbers are cleared when another project is opened, because floors belong to one project.
- Prep is unchanged: its **Requirement areas** step still applies one headcount to every floor.

## Verified

- Two floors given 300 and 40 people are written with each floor's own device counts, read back from the downloaded project.
- A blank floor uses the building number; with no per-floor numbers every floor gets the building number exactly as before.
- 0 leaves a floor with no capacity area; a project where every floor has its own number needs no building number.
- The preview's per-floor device counts match what the writer puts in the file.
- On the real Capacity page, the **People on this floor** box sends its number with the preview and with **Apply and download**, sends 0 as 0, and returns the floor to the building number when cleared.
- These checks fail if the writer uses one headcount for every floor, or if the page stops sending the per-floor numbers.
