# Home: readable tool names, a tile for each tool's own icon, and a mark on the tool last opened

Suite **2.244.0**. Tool versions are unchanged.

## What changed

### Home

- **Tool names are legible in both themes.** Each tile's name is now set in its tool's colour mixed toward white (dark theme) or black (light theme) until it clears 4.5:1 contrast on the tile. Previously Capacity, Report, Quick Walls, Scale and AP Labeler fell below 4.5:1 in the dark theme, and Prep, Cloud Manager, Squirrel and PlanTrim fell below 4.5:1 in the light theme. The tile outline is now 2px and softer until the tile is hovered or focused, when it takes the name colour. In the light theme the pale brands (Cloud Manager, Prep, Squirrel) use the darker shade their own pages use.
- **The tool last opened is marked.** Its tile carries a faint tint and the words **Last opened**. Tiles stay in alphabetical order. This is remembered in the browser only, as a page path and nothing else.
- **Capacity and Prep have their own icons.** Both previously showed the suite logo.
- **A line under the tagline says where the work happens:** "Everything runs on this computer. Cloud Manager contacts Ekahau Cloud only when you tell it to."
- **PlanTrim and Prep descriptions now say how they differ.** PlanTrim only crops; Prep crops, adds requirement areas and loads wall types. The Quick Walls description names what it edits.
- **Versions on the tiles stay blank until they load** instead of showing "v…", which also stayed if the version file could not be read.
- **The footer links, User Guide and Settings, are neutral** and show a visible focus ring.
- **Columns follow the window width.** Tiles are never narrower than 300px, so names no longer truncate and descriptions no longer wrap to six lines in a narrow window. On a maximised 1920×1080 browser window Home now uses the large-monitor sizes.
- **Keyboard focus on a tile** now shows the same lift as hover, plus a ring in the page's text colour.
- **Reduced motion:** with the operating system's reduced-motion setting on, tiles and the theme button no longer move on hover.

### Every page

- **The menu button announces whether its menu is open**, and pressing **Esc** closes an open menu.
- **The theme button draws its icon** (a moon or a sun) instead of using an emoji, and announces both the current theme and what pressing it does.
- **Menu section headings** ("Navigation", "Tools", "Help & Support") are 11px instead of 10px, and use the secondary text colour for higher contrast.

### Semantics on Home

- The page has one heading and one main region. Each tile is named by its own heading and described by its own line.

## Verified

- Contrast of every tile name on the tile and on its hover background, in both themes, is computed from the stylesheet by a new test.
- Home was checked in the browser pane in the dark and light themes at 1280, 700 and 540px wide: no name truncates, no horizontal scroll, the "Last opened" tile is marked, the menu button reports open and closed and Esc closes the menu.
- The last-opened mark is driven through its real handlers in Node, including the Squirrel pages counting as one tool.
- The full suite passes.
