## Immediate fix

The two chips inside the "Share with your Sharing Group" section (Manage members / Sync group shares) used a custom `.share-group-manage-btn` class — transparent background, underline-on-hover, no border. That's link styling, not button styling.

Switched both to standard WD button classes: `class="btn btn-sm btn-secondary"`. That inherits the whole suite-wide button treatment:

- **Pill radius**: `border-radius: 999px` (matches Cancel / Close / Add / every other WD button)
- **Border**: 1px solid nav-blue (`rgb(6, 104, 217)` in dark mode) — matches the modal's Close button *exactly* per DOM inspection
- **Padding**: `4px 12px` — small variant, appropriate for a chip in a densely populated section
- **Font**: 12px, weight 500 — same as `body.tool-cloud .btn` compact style
- **Hover**: 3D lift + shadow (from `.btn:hover:not(:disabled)`) — WD's signature interaction

Old `.share-group-manage-btn` CSS left in place for now (harmless dead code, cleaner to remove in a broader pass).
