# Cloud Manager's Share dialog reads at arm's length

Suite **2.207.1**: Cloud Manager **4.79.2**.

## What changed

### Cloud Manager

- **The Share dialog's small print is larger.** In **Sharing…** (or **Move, share, mark, overwrite → Share…**), the list of projects being shared is 14 pixels (was 12). Everything else that was 10–12 pixels is now 13: the **These N projects will be shared** heading and the list of projects left out, the **Share with someone** label and the note under the address box, the **Recent** addresses, each person's name and address, the Sharing Group section and the section for removing access. The dialog's layout and behaviour are unchanged.

## Verified

- In headless Firefox at 1366×1080 with an invented account, no text in the Share dialog is below 13 pixels, recent addresses included; before the change the note under the address box and the **Recent** label were 11.
- The full test suite passes.

## Files changed

- `web/assets/wd-tools.css`: the Share dialog's text sizes
- `tests/test_cloud_bulk_share_browser.py`: nothing in the dialog below 13 pixels
