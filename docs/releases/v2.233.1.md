# Cloud Manager: the search box's × also resets the letter bar to All

Suite **2.233.1**, Cloud Manager **4.90.1**. Every other tool is unchanged.

## What changed

### Cloud Manager

- **The × in the search box now also clears the A-Z letter filter.** The × sits at the right-hand end of the **Search...** box above the list. Previously it emptied the box and left any selected letter in place, so the list stayed narrowed to that letter. It now returns the list to **All**, scrolled to the top.
- **The letter is cleared even when the box is already empty.** Pressing × with only a letter selected shows every letter again.
- **The "Clear search" button in an empty-list message behaves the same way.**

## Verified

- The real `clearSearch` function is run against recording stubs: the box is emptied, the selected letter is dropped, the list is redrawn once and sent to the top. With a letter alone selected, the same happens. With neither set, nothing is redrawn.
- With the letter reset removed, these checks fail.
