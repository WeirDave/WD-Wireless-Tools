# Report: directional markers are described as cones

Suite **2.239.1**. Report **2.73.4**. Other tools are unchanged.

## What changed

### Report

- **The directional marker on a floor plan is now called a cone, matching what is drawn.** The placement map key reads *Directional, cone shows aim*, and the note under each floor plan on the Antenna Aim Sheet reads *The cone on a marker points the way its antenna is aimed.*
- **The placement option is relabelled.** In the Report options for the placement map, **Show aiming cones on directional APs** (off by default) replaces *Show aiming arrows on directional APs*.
- **The report descriptions use the same word.** The descriptions of the Antenna Aim Sheet floor plans and of the scalable floor plan per floor now say cone and cones.

No setting changes. The option keeps its existing saved value.
