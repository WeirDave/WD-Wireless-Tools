# Cloud Manager: a comparison names which copy each difference is on and which is newer

Suite **2.246.16**, Cloud Manager **4.93.0**.

## What changed

### Cloud Manager (Projects tab, "Check what differs")

- **Every count in the "Real changes" line now names its side.** The line used "added" and "removed", which did not say whether the item was in the cloud copy or in the local file. It now reads, for example, "Real changes: access points (3 changed, 1 only in cloud, 2 only in local)". "Only in cloud" means the cloud copy has the item and the local file does not; "only in local" means the reverse; "changed" means both have it and it differs.
- **The line also says which copy has the later date.** After a comparison that finds real changes, the row adds "The cloud copy has the later date." or "Your local file has the later date.", so the side to keep can be chosen from the row. Before, the later-date sentence disappeared as soon as a comparison had been run.
- The "What differs" list under the line already used "only in local" and "only in cloud" and is unchanged.

## Verified

- Tests compare two archives with a different access point on each side and check that each count appears under the correct side, and that "added" and "removed" no longer appear.
- A test renders the row for a comparison with real changes and checks that the correct "later date" sentence is present and the other is not. Both tests fail with the change reverted.
- The full suite passes.
