Report gets a **Bill of Materials** template. The BOM entry has been sitting `coming-soon` in the gallery for several releases; it's now fully rendered with real project data.

Suite `v1.20.0 → v1.21.0`. Report `v2.7 → v2.8`.

## What's new

New template in the Report gallery: **Bill of Materials** (amber-accented cover). Meta report — always looks at the whole project regardless of the AP directional/omni filter.

### Sections rendered

1. **Cover page** — site name, total AP count, floor count, logo, date.
2. **Access point quantities** — vendor × model × qty table, sorted by vendor then quantity. Grand total row.
3. **Antenna quantities** — antenna model × coupling × band × gain × qty table. Grand total row. Antennas are counted **per radio-to-antenna assignment**, not per physical part — an AP with a dual-band external antenna kit contributes 2× to the count.
4. **Procurement notes** — what this BOM does and doesn't cover. Explicitly lists things NOT derived from Ekahau (mount hardware, cable, PoE injectors, switch ports) with the reasoning.

### Sidebar options

- **Show external antennas only** — hides `INTEGRATED_ANTENNA` rows so the table only lists procurement-relevant external antenna kits. Default off. When on, projects with all-integrated antennas render a friendly empty state instructing the user to turn it off.

## Verified end-to-end

Loaded the same real 9.6 MB `.esx` (CLMB2 — Arsenal Hangar, Columbus):

- Cover: `Report · Bill of Materials`.
- AP quantities table: 3 vendor+model rows + total row **= 11 APs total** (matches project truth).
- Antenna quantities table (default view): 8 antenna rows + total row **= 44 antennas total** (matches the 44 radios in the project — one antenna per radio assignment).
- External-only toggle on: table correctly renders the empty state ("No antennas match the current filter. Try turning off 'External only'…") because CLMB2 is an integrated-antenna project. Toggle off → table returns.

Round-trip verified. Zero console errors on any state.
