# Settings: keyboard-safe sections, labelled fields, readable buttons and an unsaved-changes marker

Suite **2.246.0**. Tool versions are unchanged.

## What changed

### Settings (Menu → Suite Settings)

- **A section can no longer be folded away on a wide window.** On a window wider than 1000px the open section's heading is the page title. Pressing Enter or Space on it used to fold the section and leave an empty page, which only a click on the section list could undo. The heading now ignores the keypress and is skipped by Tab. On narrower windows the sections still fold as before.
- **An "Unsaved changes" marker appears beside Save once anything has been edited.** It clears on Save.
- **Cancel asks before discarding.** If there are unsaved changes, Cancel and "Re-run Setup Wizard" ask "Discard your unsaved changes?", and closing or reloading the tab asks as well. With nothing changed they act at once.
- **Save and Cancel are not shown on "PlanTrim, Rename and the rest" or "Backup & restore"**, which have nothing to save. They return as soon as something is edited elsewhere.
- **"Forget Login" and "Reset Organizer Defaults" say what they do.** Both apply immediately, not on Save, and the page now says so beside each button. Forget Login asks first and is greyed out, with the reason as its tooltip, when Cloud Manager is not signed in. Reset Organizer Defaults asks first, names the rename rules it also clears, and says it replaces unsaved changes on the page.
- **"Sites open as" in the Cloud Manager section looks like the other two radio groups.** Its options had been drawn as small uppercase grey labels. The three groups are now stacked lists, one option per line.
- **Plain buttons (Cancel, Clear, "Open Report" and the like) use the suite's secondary button colour** instead of the browser's grey. "Open Report" is drawn as a button rather than a purple underlined link.
- **The section list stays put.** It used to move about 270px sideways when a short section was opened. The column now keeps a fixed width and a reserved scrollbar gutter.
- **The Save and Browse buttons, and the muted text, are readable.** White on the Cloud blue measured 2.77:1; the button blue is now that blue mixed toward black, about 5.2:1. Empty values ("Not set"), the "What is saved" titles, "Changed in …" lines, "Re-run Setup Wizard" and the drag and remove marks are lighter in the dark theme. Input outlines and placeholder text are stronger.
- **The page is a proper document for screen readers and the keyboard.** "Suite Settings" is the page heading and each section title is a heading. The settings are the main landmark and the current section in the list is marked. Every field has a name that is read out, including the Squirrel lists, the subfolder rows and the destination rows. Each group of radio buttons has a group name. Checkboxes and radio buttons are larger, and the browser tab is titled "Suite Settings".
- **Copy:** the Squirrel section says its lists are comma-separated. The Report section no longer carries a paragraph about a change made in v2.152.0, and its cover-image note is shorter. The Windows Terminal tab note in General is shorter.

### Buttons on every page

- **Blue primary buttons (`btn-blue`) use the darker button blue on every page**, for example Browse, Save and Export. The "Update" button in the update banner and its detail text change the same way.

## Verified

- The Settings page was checked in the browser's built-in Chromium engine, in dark and light, at a wide window and at 540px. The Firefox, Chrome and Edge CI jobs run on the push.
- New tests cover the heading that cannot fold, the field labels, the radio groups, the unsaved-changes marker, Cancel, the buttons that act at once, and the text and button contrast in both themes.
- The full suite passes.
