*"Can we make a custom wall pattern in our program to account for Framery Ones? So every file will have those so I can model correctly."* — Dave.

Framery One phone pods are all over Dave's sites — steel-framed acoustic booths with a glass door, sitting on the floor plan as a ~1×1 m enclosure. Ekahau doesn't ship a wall type for them, so up to now Dave had to pick "close enough" (Cubicle underestimates the loss; Steel Rollup Door overestimates it) and eyeball the difference.

**Fix.** Added **Framery One** as a first-class wall type in the *Recommended by WD* template. It's slotted alphabetically between Elevator Shaft and Marble, with a distinct purple color (`#9C27B0`) so it pops against the beiges and grays already in the palette.

Propagation values reflect the pod's construction — a sandwich of steel bracing, acoustic wool, and fabric-fronted panels ~6 cm thick, with a laminated glass door:

- Attenuation: `100` (2.4 / 5 / 6 GHz)
- Reflection: `0.405` (steel-frame reflectivity)
- Diffraction: `11`
- Thickness: `0.06 m`

Heavier than a cubicle (10) and drywall (30), lighter than a steel fire door (325). Dave can tune the numbers per-project if a specific site calls for it — the point is the *type* is now waiting in the template so drawing the pod outline is a one-click job.

Since the *Recommended by WD* template auto-applies on file open (for Dave), every .esx he touches from here on will already have the type available at draw time.
