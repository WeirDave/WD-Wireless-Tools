# Cloud Manager: the two directions of a choice now look the same

Suite **2.232.1**, Cloud Manager **4.89.1**. Every other tool is unchanged.

## What changed

### Cloud Manager

- **Opposite-direction buttons have the same weight.** When a row offers one button for each way a choice can go, both are drawn as the same outlined button, one under the Cloud column and one under the Local column. Previously one of the two was filled and the other outlined, and which one was filled differed from row to row. This applies to:
  - **Cloud → Local** and **Local → Cloud** on a project or a site whose names disagree.
  - **Rename folder to match** and **Rename cloud site to match** on a project whose folder was renamed.
  - **Replace cloud with local…** and **Cloud newer · download** on a project whose cloud copy is newer.
- **"Replace cloud with local…" is now visibly a button.** It was drawn with no border and no background, so on a project whose cloud copy is newer it read as plain text. It now has the same border and background as the download button beside it.
- **"Local newer · replace cloud" is visible before a comparison.** It had the same borderless style until **Check what differs** had been run. It now appears as an outlined button from the start, and becomes filled once a comparison has been made.
- **Emphasis is kept for the read-only check.** **Check what differs** is still the filled button on a row where the two copies' dates differ and nothing has been compared, because it changes nothing and settles which direction is wanted.

## Verified

- Every row type above is rendered with the real row code and the buttons are read back from the markup: the two directions carry identical styling, and none of them is borderless.
- With the previous code the same checks fail, on each of the rows listed.
- The related Cloud Manager tests pass.
