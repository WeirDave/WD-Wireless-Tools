Two follow-ups from v1.9.0 based on the maintainer squinting at the deck and asking "what the hell is going on there":

1. **The deck is bigger.** Was 560px fixed at ~12px font — cramped on a full monitor, borderline unreadable if you weren't looking for it. Now scales proportionally with the viewport: `clamp(600px, 42vw, 820px)` — big enough to actually read at a glance, still leaves the app fully visible around it. All text sizes bumped 1-3px (title 12→14, buttons 11→13, undo timer 10→12).
2. **Titles inflect to past tense when done.** A completed rename card was still titled "Renaming …" — which read as active/hung even though the green check said Done. Now:
   - Running: `Renaming X → Y`
   - Done: `Renamed X → Y`
   - Failed: `Failed to rename X → Y`
   - Cancelled: `Cancelled rename: X → Y`

Same for Move / Download / Upload / Delete / Merge / Create / Undo. The card unambiguously reads as "finished, but here's your undo window" instead of "still doing something."

Suite `v1.9.0 → v1.9.1`. WD Cloud Manager `v4.0 → v4.0.1`.

## What changed

### Sizing

- Deck width: fixed 560px → `clamp(600px, 42vw, 820px)`
- Deck max-height: 60vh/520 → 72vh/640
- Border radius: 10 → 12; shadow bumped
- Header padding: 10/12 → 14/18; summary font 13→15
- Card padding: 8/10 → 12/14; icon column 26→32; title font 12→14; stage font 11→12
- Progress bar height: 4→6
- Buttons: font 11→13, padding 4/10 → 6/14, weight 500

Below 700px viewport the deck goes full-width (minus 32px margins) so it stays usable on narrow windows.

### Tense flip

New helper `_titleForStatus(op)` in `cloud.js` — pattern-matches the enqueued title verb prefix and swaps it based on `op.status`. Present-participle prefixes recognized: `Renaming / Moving / Downloading / Uploading / Deleting / Merging / Creating / Undo:`. Falls through to the original title if nothing matches.
