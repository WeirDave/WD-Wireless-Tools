# Cloud Manager: an expired Ekahau Cloud sign-in returns to the sign-in screen

Suite **2.177.1** ships **Cloud Manager 4.72.1**. The Cloud Manager page shows the Cloud Manager number, not the suite number.

## What changed

### Cloud Manager: expired sign-in

- **When the saved Ekahau Cloud session expires, Cloud Manager now returns to its sign-in screen** with the message "Your Ekahau Cloud sign-in has expired. Use "Log in to Ekahau Cloud" to reconnect." Clicking **Log in to Ekahau Cloud** opens Ekahau Cloud in the browser; once signed in there, Cloud Manager picks the new session up and loads the list again. Nothing needs to be turned on.
- Before this release an expired session showed an empty list with the error `401 Client Error: Unauthorized for url: https://www.ekahau.cloud/site-management-api/v1/sites`. The address in that message was correct; the 401 is Ekahau refusing the expired session, not a wrong URL.
- The expired session is now discarded as soon as Ekahau refuses it. Previously it was kept and re-sent on every refresh, including every automatic Live refresh, until the app was restarted.
- Any other failure (Ekahau rate-limiting, a server error) still leaves the list on screen and shows the message, as before.

### Documentation: the Ekahau Cloud address

- The README, SECURITY.md and the user manual named `cloud.ekahau.com` as the place to sign in. Cloud Manager reads its session from `www.ekahau.cloud`, so all three now name that address.

## Verified

- An Ekahau 401 on the Sites and Projects listing is reported as an expired sign-in, the session is discarded, and the next refresh re-checks saved and browser sessions before reporting again.
- A redirect loop from Ekahau is still treated as an expired sign-in; a 500 is not.
- The page returns to the sign-in screen and stops Live refresh on an expired sign-in, for both the main listing and the Duplicates tab, including when the failure arrives on a background refresh.
- No document in the repository names an Ekahau Cloud host other than the one Cloud Manager uses.
