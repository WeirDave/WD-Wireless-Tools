# Report: each floor has its own columns and rows in Configure Grid

Suite **2.249.5**, Report **2.79.0**. The other tools are unchanged.

## What changed

### Report

- **Columns and rows are set per floor.** In the **Configure Grid** dialog (Configure step, **Section grid** option, the button on the right), the **Columns** and **Rows** controls apply to the floor selected in the list on the left. A mezzanine over part of a building can now be cut into fewer sections than the floor under it. Floors nobody has changed stay automatic.
- **The dialog shows which floor the size is for.** The line under the controls reads, for example, "4 × 3 grid on this floor: 12 cells, 18 APs".
- **Changing one floor's grid no longer touches the others.** Combined sections on a floor are cleared only when that floor's own columns or rows change; every other floor keeps its combined sections.
- **Reset to Auto** returns only the floor on screen to its automatic columns and rows, together with its crop and combined sections, as before. Other floors are not changed.
- **Apply to All Floors** copies the floor's columns and rows, together with its crop position and combined sections, to every floor included in the report. A floor with no size of its own passes that on, so the other floors become automatic too.
- **The Section grid button in the options panel** reads the size when every included floor has the same one, **Auto** when none has been set, and **Per floor** when they differ.
- **Projects saved with one size for every floor are unchanged.** That size applies to each floor until the dialog is next used, then becomes each floor's own size; no floor changes until its numbers are changed. A project that has never been set up still starts from the last project-wide size remembered by an earlier version. Sizes set per floor are not carried to other projects.
- **A floor's size is remembered with the project**, with the crop and combined sections, and returns when the file is opened again or another report is chosen.
- The **Configure Grid** help text, the tooltips on **Apply to All Floors** and **Reset to Auto**, and the User Manual describe the per-floor behaviour.

## Verified

- The full suite passes. New tests open the real dialog and drive the real buttons: a change on one floor leaves the other floors automatic, switching floors shows each floor's own numbers, **Reset to Auto** and **Apply to All Floors** act as described, a project-wide size is converted when the dialog opens, and combined sections follow their own floor. The printed report is checked for different section letters on two floors. The new tests fail when the per-floor lookup or the "same as automatic is not stored" rule is removed.
- The saved-grid store is tested for per-floor sizes, including entries that are out of range, not numbers, or for an empty floor id.
