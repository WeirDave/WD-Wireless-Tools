# Report: the AP Placement Map names a split floor once

Suite **2.178.2** ships **Report 2.65.6**. The Report page shows the Report number, not the suite number.

## What changed

### Report → AP Placement Map

- **A floor split into sections no longer prints its floor heading twice.** When a floor plan is large enough to be divided into a section grid, the page opened with the floor heading (for example "Floor 0", with the plan name and AP count beside it), then the "Floor plan split into … sections" notice, then the section index opening with "Floor 0" again. The second heading is gone; the index now sits directly under the notice.
- Nothing needs to be turned on. It applies whenever the placement map splits a floor into sections, which is set by the section options in the Configure step.
- Other reports that use the same section index under a heading of their own, such as the AP Location report, are unchanged.

## Verified

- The real placement page renderer, run through the section-grid path, produces the floor heading exactly once; the same check finds it twice against the previous release.
- The section index still carries its floor heading when it is used without a page heading above it.
