# Cloud Manager draws other people's projects in one colour, buttons included

Suite **2.214.0**: Cloud Manager **4.84.0**. Every other tool is unchanged.

## What changed

### Cloud Manager

- **One colour for "somebody else's".** A project owned by another person is now violet everywhere it appears: the ownership dot in front of the name, the name, the owner address, and the **"Others"** button in the **Owner** toggle above the list. The dot and the **"Others"** button were orange before, while the name and address beside them were violet.
- **The controls on those rows follow.** On a row owned by someone else, the recommended button in the band under the row (for example **"Check what differs"**), the row's tick boxes, the row menu and focus outlines are violet. On the signed-in user's own rows they stay blue. Unavailable controls stay grey.
- **The rest of the page agrees.** The **"external"** summary card, the **"Marked External"** badge, the **"Owner filter: Others"** notice above the list, and other people's addresses on the **Duplicate Projects** tab use the same violet. The **"All"** button in the Owner toggle is now neutral grey, since it shows both.
- Applies in both the light and dark themes.

## Verified

- In Chromium, light and dark themes, on a list with one project owned by the signed-in user and one owned by a colleague: every ownership mark and the recommended button on the colleague's row read back as the violet token, the user's own row kept the blue, and nothing ownership-related is orange.
- A new browser test reads those colours off the rendered page in Firefox, Chrome and Edge, and fails if the band under a colleague's row stops taking their colour.
- The full test suite passes.
