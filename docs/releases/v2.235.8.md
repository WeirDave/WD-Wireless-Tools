# Report: floor plan maps no longer print on a black background

Suite **2.235.8**, Report **2.73.2**. Every other tool is unchanged.

## What changed

### Report (AP Placement Map and every report that crops a floor plan)

- **Floor plans print on white.** A CAD floor plan has no painted page, so its empty areas are transparent. The cropped section maps were re-encoded as JPEG, which has no transparency, and the empty areas came out black: each section of the AP Placement Map printed as a black rectangle with the plan lines lost in it and the AP labels standing alone. The crop now paints white underneath the plan first.
- **Automatic cropping finds the real edge of the plan.** The measurement that trims empty margin around a plan on the coverage and hotspot pages treated transparent areas as content, so it found content everywhere and left the plan uncropped. It now measures on a white page, so margin counts as margin.
- Nothing needs to be switched on. Reports are rebuilt from the project when generated, so running the report again produces the corrected maps.

## Verified

- A transparent plan with one dark box is cropped for a section map and for automatic cropping: the section map is white around the box, and the automatic crop narrows the view to the box.
- The new test fails with the white fill removed.
