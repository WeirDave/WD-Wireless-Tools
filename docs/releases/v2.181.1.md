# Squirrel Rename: .esx project files can be renamed in place

Suite **2.181.1** ships **Squirrel 1.27.10**. The Squirrel pages show the Squirrel number, not the suite number.

## What changed

### Squirrel → Rename, File Cleanup Rules tab

- **`.esx` files now appear in the preview and are renamed with everything else.** Before this release the File Cleanup Rules tab skipped `.esx` files entirely, so browsing to a projects folder showed nothing to rename. The extension is kept as it is; the rules (**"From the start (regex)"**, **"From the end (regex)"**, **"Find (regex) / Replace with"**, **"Filename case"**, **"Word separator"**, **"Prefix"** and **"Suffix"**) act on the name in front of it.
- **Files sitting loose in the chosen folder are included** alongside the files in each site folder under it. Previously, once the folder held any site folders, its own top-level files were ignored.
- **A blank rule set now says what it found**, for example "12 files found, .esx included. None change with the current rules", instead of "No files change with the current rules", which read as though the folder was empty.
- Folders Squirrel always skips (`backups`, `archive`, `output` and the others listed in Squirrel's settings) are still skipped.

### Squirrel → Rename, File Convention tab

- Loose files in the chosen folder are included next to the files in each site folder, the same as above. With a CSV site directory loaded, only files whose folder matches a site in the CSV are renamed, as before.

### Squirrel → Rename, the Browse… button

- The line next to **"Browse…"** and the folder dialog's title now say that the dialog lists folders only. The files in the chosen folder, `.esx` included, appear in the preview at the bottom of the page after a folder is picked.

## How to use it

1. Open **Squirrel → Rename**, click **"Browse…"** and pick the projects folder (or any folder holding the `.esx` files).
2. Open the **"File Cleanup Rules"** tab and set a rule, for example **"Word separator"** or **"Find (regex) / Replace with"**. Every rule is blank by default, so nothing is renamed until one is set.
3. Check the preview, then click **"Apply Rename"**. **"Undo"** reverses the last run.

## Verified

- New tests drive the preview and apply routes against a synthetic projects folder with `.esx` files in site folders, loose at the top level, and in a `backups` folder: every `.esx` outside `backups` is previewed and renamed on disk, and the `backups` copy is untouched. A blank rule set reports the number of files scanned.
- Each new test was confirmed to fail with the change it covers reverted.
