Squirrel's Organize screen used to dump you straight into a per-site file table with checkboxes, destination dropdowns, and detection banners — closer to Cloud Manager's ledger than the "quick script to sort my files" it was meant to be. It now leads with one line — how many files move, how many stay — and a single Organize All Files button. The full file-by-file breakdown is still there, just opt-in behind a **Show File Details** toggle.

**New: Bulk Rename**, its own card and tool on the Squirrel home screen. Pick a folder, toggle rules (lowercase, strip prefix, prepend site code, collapse spaces, regex find/replace), see a live preview of exactly which files change and how, then apply. It shares the same saved rule set Organize already applies at move time, so the two stay in sync — and those rules no longer live in a confusing, unexplained corner of Settings.

Opening Squirrel now always lands on the four action cards. A remembered last folder shows up as an explicit "Continue with this folder…" choice instead of silently skipping straight to the file summary.

Settings got a real pass: widened to 1366px and reflowed into a grid instead of one long narrow column, an explanatory intro line was added, and the Create Folder naming template section now has a full token legend (what `{code}`, `{name}`, `{city}`, etc. actually mean) plus two worked examples instead of one bare, jargon-y one.

Also in this release: Cloud Manager's row action icons (rename/delete/reveal) only fade in on row hover, which made the browser's native tooltip unreliable — swapped for a delegated tooltip that shows consistently. And a suite-wide consistency pass: every tool page now has the standalone Home button (Quick Walls and Report were missing it on both of their screens), tool logo sizing and header-to-graphic spacing is the same across Squirrel/Scale/Quick Walls/Report, Report's header lost a stray duplicate icon, and Quick Walls/Report's drop screens got real descriptions of what the tool does instead of just a one-line tagline.

Suite `v1.32.5 → v1.33.0`.
