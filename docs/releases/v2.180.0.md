# Prep: a headcount for each floor

Suite **2.180.0** ships **Prep 1.12.0**. The Prep page shows the Prep number, not the suite number.

## What changed

### Prep → Put a requirement area on every floor

- **Each floor now takes its own headcount, the same way Capacity does since 2.179.0.** Before this release Prep put the same number of people on every floor, so a building of several storeys was written with the whole building's devices on each one.
- **Where it is:** Prep, step **1 — What to do**, **Put a requirement area on every floor**. The number beside the template now reads **each floor for … people**. It is the default for every floor. Each floor listed under **Requirement areas** in step **2 — What that would do** has its own **People on this floor** box.
- **Default:** blank. A blank box uses the number in step 1, which is shown greyed inside the box. Type a number to size that floor for that many people. Type **0** to leave the floor alone: no area is written on it.
- **0 also protects a placeholder area.** Prep normally re-measures a requirement area that still covers the whole plan once there are walls to measure, by replacing it. On a floor set to 0 that area is left exactly as it is, with its devices, rather than removed with nothing to replace it.
- The preview updates when you leave the box. Each floor shows its own device count, and the last line totals the people and devices across the floors being written. **Prepare** uses the same numbers.
- Per-floor numbers are cleared when another project is opened.

## Verified

- Two floors given 300 and 40 people are written with each floor's own device counts, read back from the prepared project; with no per-floor numbers every floor gets the step 1 number exactly as before.
- A floor set to 0 gets no area. A floor set to 0 that carries a whole-plan placeholder keeps that area and its 77 devices, where the re-measure would otherwise have removed it.
- On the real Prep page, each floor's box sends its number with the preview and with **Prepare**, sends 0 as 0, returns the floor to the step 1 number when cleared, and starts empty on the next project.
- These checks fail if the re-measure ignores a floor set to 0, or if the page stops sending the per-floor numbers.
