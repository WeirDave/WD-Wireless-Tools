# Prep: Wall swap is no longer a stage

Suite **2.196.0**, Prep **2.1.0**.

## What changed

### Prep

- **The rail now has three stages: 1 · Trim the canvas, 2 · Requirement areas and 3 · Wall types.** The fourth, **Wall swap**, is gone from the rail, from the settings panel and from the server's project facts.
- Prep is for getting a new project's `.esx` ready to work in. Changing the type of walls already drawn, after an import has put concrete and steel on the same type, is a later job and stays in Quick Walls' **Wall Swap**.
- Nothing else in Prep changes. **Prepare** writes the same trim, requirement areas and wall types as before.

## Verified

- Prep's markup is read for the stages its rail opens: trim, areas and walls, in that order, each with its own panel and no other panel. No text on the page offers Wall Swap. The test fails on the 2.195.0 page.
- Every existing Prep test passes, with the stubs that only stood in for the removed stage taken out.
- The full test suite passes.

## Files changed

- `web/prep.html`: the Wall swap stage and its panel removed
- `web/assets/js/prep.js`: the stage list and `renderSwap` removed
- `server.py`: `wallCount` dropped from Prep's project facts
- `web/assets/wd-tools.css`: `.pb-stage--optional`, used only by that stage, removed
- `docs/USER_MANUAL.md`, `docs/prep-workbench.md`: Prep has three stages; Wall Swap is in Quick Walls
- `tests/test_prep_has_no_wall_swap.py`: new
- `tests/test_prep_applies_his_wall_template.py`, `tests/test_prep_repairs_black_plans.py`, `tests/test_prep_trim_options.py`: stubs for the removed stage removed
