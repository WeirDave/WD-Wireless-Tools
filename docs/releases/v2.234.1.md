# Quick Walls: Visual Swap lists a wall type once, however many copies the project holds

Suite **2.234.1**, Quick Walls **7.78.1**. Every other tool is unchanged.

## What changed

### Quick Walls: Visual Swap

- **Each wall type name is listed once.** A project can contain several wall types with the same name, such as a copied type. Visual Swap used to list every copy, so "Elevator Shaft" or "Door, Steel Fire/Exit" could each appear twice. The lists now show one entry per name. This covers **Change checked to** under **Selected**, and **From** and **To** under **Quick swap by type**.
- **The legend and the selection follow the same rule.** **Wall types on this floor** shows one row per name with the walls of every copy counted together, and clicking it selects all of them. The groups under **Selected** are one per name as well.
- **Choosing a name covers every copy.** **Quick swap by type** with **From** set to a name moves the walls drawn with any copy of it. Undo returns each wall to the copy it was drawn with.
- **A swap to a type's own name changes nothing.** **Swap** and **Swap all** report that there is nothing to change instead of moving walls between copies of the same name.
- **Which copy the walls arrive on.** A swap to a name uses the copy that the most walls in the project already use, and the first in the project's list when the counts are equal.
- **Only identical names are combined.** Case and spacing are ignored. A name that differs in any other way, such as "Window, Thick(Copy)", stays a separate entry. The wall types in the project are not edited or removed.

## Verified

- A project with same-name copies is opened in the real page in Chrome, Edge and Firefox. Every dropdown is read back and lists each name once, the legend and the **Selected** groups count the copies together, and the real **Swap all** handler moves the walls from every copy.
- Undo restores each wall to the copy it was drawn with.
- With the change removed, these checks fail.
