# The file-based tools' opening screens fit on a laptop screen

Suite **2.175.5** ships **Quick Walls 7.69.1, Prep 1.10.1, Capacity 1.4.2, PlanTrim 1.19.1, Report 2.65.3 and AP Labeler 2.13.2**. Each tool's page header shows that tool's own number, not the suite number.

## What changed

### Quick Walls, Prep, Capacity, PlanTrim, Report and AP Labeler: the opening screen

This is the screen each tool shows before an `.esx` is opened: the tool's logo, a short description, the dashed **"Drop .esx file here or click to browse"** box, and the numbered steps underneath.

- **On a window 860 pixels tall or less, the logo is smaller (104 pixels instead of 180) and the spacing above the drop box is tighter**, so the drop box, **Open from disk…** where the tool has it, and the numbered steps are all on screen without scrolling. Before this, Quick Walls, Prep, Capacity and PlanTrim scrolled at both 1280×720 and 1366×768, and Report and AP Labeler scrolled at 1280×720.
- **Taller windows are unchanged**, and the logo stays clear of the bar across the top of the page at every size.
- Nothing needs to be turned on. The Home page's nine tool tiles already fit a laptop screen and are unchanged; Squirrel's opening screen was changed in 2.175.4.

## Verified

- Each of the six tools was measured in a browser at 1280×720, 1366×768 and 1920×1080. At every size the steps ended above the bottom of the window, the page did not scroll, and the logo sat below the top bar.
- A new automated test takes the same measurements in Chrome, Edge and Firefox wherever they are installed. With the change removed, the fits-the-screen check fails for Quick Walls, Prep, Capacity and PlanTrim. A version with the top spacing cut too far, which put the logo under the top bar, fails the logo check.
