*"I don't really like the fact that we go from blue to green to teal ... the colors not terribly far apart"* — the maintainer, on the home page card colors.

Blue, green, and teal sit within about 65° of each other on the color wheel, so Cloud Manager, Quick Walls, and WD Report read as one blurry blue-green cluster at a glance — worst in the dark theme. Fix: recolor the trio for real separation, and make each tool's ".esx" drop zone match its own brand color instead of defaulting to blue everywhere.

- **Cloud Manager** — steel blue → a brighter cloud/sky blue (`#0ea5e9`)
- **Quick Walls** — olive green → true forest green (`#15803d`)
- **WD Report** — teal (the color literally sitting between blue and green) → a deep wine/berry (`#9F1B58`), moved out of the cluster entirely and into the open gap between purple and amber
- **WD Scale** (purple) and **WD Squirrel** (amber) — unchanged, they already had good separation

The five tool colors are now spaced ≥45° apart on the wheel, versus a worst case of 25° before. The Walls and Report drop-zone boxes (border, hover/dragover fill, and the ".esx" label) now use each tool's own color instead of a shared blue default.

Suite `v1.29.10 → v1.29.11`. No individual tool version changes — this is a shared-stylesheet update.

- `web/assets/wd-tools.css` — new `--blue`/`--green` values, new `--rose` token replacing Report's `--teal` usage, per-tool drop-zone border/hover/`.ext` color rules for Quick Walls and WD Report.
- `web/home.html`, `web/pages/hosted-index.html` — Report's home-card class `card teal` → `card rose`; suite version chip.
- `web/pages/hosted-index.html`, `web/pages/hosted-cloud-stub.html`, `web/pages/hosted-organizer-stub.html` — hardcoded CTA button colors updated to match the new blue.
