**Quick Walls.** Shortcut slots in the Keyboard Shortcuts panel are now draggable onto each other — drag slot `[3]` onto slot `[7]` to swap or move that assignment directly, instead of having to drag a wall type back in from the list. The bundled "Recommended by WD" template is renamed to **WD Template** everywhere (dropdown, guide, README) since it's Dave's own setup, not a universal recommendation — the underlying file was renamed too (`Recommended by WD_walltemplate.json` → `WD Template_walltemplate.json`), and a small migration keeps anyone with the old name cached in browser storage pointed at the new one. Its default keyboard shortcuts were also reordered: `[1]` Dry Wall, `[2]` Concrete, `[3]` Thick Window, `[4]` Solid Wood Door, `[5]` Steel Fire/Exit Door, `[6]` Steel Rollup Door, `[7]` Warehouse Shelf, `[8]` Framery Boxes, `[9]` Elevator Shaft.

**Report.** New **"Split large floor plans into zoomed sections"** option on the Directional Antenna Installation report, for buildings too large for one overview page to keep AP labels legible (e.g. a 950k+ sqft warehouse). When enabled, each floor plan is auto-divided into a lettered/numbered grid sized from floor area and AP density, with a section-index locator map up top and one zoomed, canvas-cropped page per populated section (empty sections are skipped and noted). Also in this release: the old "Phone Hotspots Detected" report is now **Interference / Rogue Devices** — it still catches iPhone/Android/MiFi hotspots, but now also flags any other SSID transmitting on a 40MHz+ channel as a plausible rogue interferer, scores each detection Low/Medium/High severity by channel width and band, and colors each floor's walk-path overlay by the worst severity seen there.

**Cloud Manager.** The ledger header now shows the actual configured path next to "Local Folders" (e.g. "Local Folders (12) - C:\Projects\Ekahau") so you know at a glance where it's scanning from, with the full path on hover if it's truncated. Fixed a bug in the Tree view where the "Unassigned Projects — no site" section disappeared entirely whenever a jump-letter filter was active, even if an orphan matching that letter (and the search box) existed — it's now filtered by letter like everything else instead of being hidden outright.

**Squirrel.** Bulk Rename's rule set was overhauled — prefix/suffix, separator normalization, and case rules replace the older strip-prefix/lowercase/regex-only set, with a `detect_rename_style` backend helper to seed sensible defaults from existing filenames. Create Folder can now target an **existing** folder via a searchable dropdown, not just create a new one from the naming template. The tool's URL moved from `/organizer` to `/squirrel` (and `/guide-organizer` to `/guide-squirrel`) with a 302 redirect kept on the old paths so nothing breaks for anyone with the old link bookmarked. The startup console banner is now plain ASCII so it doesn't crash under non-UTF8 terminals or captured/piped stdout.
