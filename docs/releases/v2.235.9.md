# Sixteen fixes: safer project colours, Cloud Manager menus and "Fix names inside files", safer overwrites, Windows installer

Suite **2.235.9**. Cloud Manager **4.90.6**, Quick Walls **7.79.1**, Squirrel **1.30.1**, Report **2.73.3**, PlanTrim **2.3.1**, AP Labeler **2.19.3**, Prep **2.8.2**. Scale, Capacity and the other tools are unchanged.

## What changed

### Project files

- **Colours read from a project can no longer alter the page.** A wall, area or AP colour in a loaded `.esx` is now accepted only if it is a hex value or an `rgb()`, `rgba()`, `hsl()` or `hsla()` value made of the characters a colour can contain. Anything else is drawn as grey (`#888`). Previously a crafted value could close the attribute it was written into and add attributes of its own. Ekahau's own colours are unaffected. Applies to Quick Walls (wall cards, the shortcut slots, area cards, the Visual Swap legend) and AP Labeler (the colour order list and its swatches). A wall's shortcut number is also now always printed as a number.
- **Prep checks a project opened from disk.** Prep already ran the archive safety check on an uploaded project; it now runs the same check on one chosen from a folder.

### Saving projects

- **A failed save no longer damages the previous result.** PlanTrim's "(trimmed)" project and Prep's "(prepared)" project are written to a temporary file and renamed over the target in one step. On Windows the earlier method could copy over the existing file, so a failure part-way left it truncated. A leftover temporary file is also removed if writing fails.
- **PlanTrim no longer misreads SVG size.** A floor plan SVG whose root element carries `stroke-width` or `data-height` is no longer measured, or rewritten, using those values in place of its real width, height and `viewBox`.

### Cloud Manager

- **Fix names inside files** (toolbar button on the Projects list, acts on the selected rows) now passes each project's id and always clears the row's busy mark. Previously a "taking longer than expected" notice could appear 30 seconds later for files that had finished.
- **"None of these"** on a held-back file now works for Windows paths. The button silently did nothing when the path contained backslashes.
- **Row action menus close** when a click lands elsewhere, when Escape is pressed, and when an item is chosen. Opening a second row's menu closes the first. Previously an open menu stayed over its row until its own button was clicked again.
- **The list recovers after a failed first load.** If the first load of the list failed and a later background refresh succeeded, the refreshed list is now drawn instead of the page staying empty.

### Report

- **Floor plan image type is read from the file itself**, not from the project's recorded format, so a plan whose recorded format is wrong still loads in the report.

### Squirrel and Cloud Manager (folder picker)

- **Paths outside the Windows ANSI code page survive the folder picker.** The native folder dialog now returns its result as UTF-8, so a folder name containing characters such as accented or non-Latin letters comes back intact.

### Suite

- **The in-app user manual returns to the section last read.** The saved position was overwritten by the first page draw before it was read.
- **One server-version check instead of two.** An older, unconnected check polled the server every 30 seconds in every open tab, and could remove the working update banner. Only the working check remains.
- **A refused in-app update is written to the log** (About → Diagnostics shows the log path) as a warning, with the reason.
- **A tooltip on the Home page** no longer produces stray attributes on its element.
- **Share recipients:** a plain address typed before a `Name <address>` entry is no longer dropped, and a long list of plain addresses is parsed in linear time.

### Windows installer

- **`install.ps1` no longer stops on git's progress messages.** Windows PowerShell 5.1 turned git's normal stderr output into errors, which aborted the install or update. Git calls now run with errors set to continue and their output is read as text.

### Development

- `requirements-dev.txt` now lists `pymupdf`, which a print test imports. A new check fails if a test imports a library that no requirements file lists.

## Verified

- Each fix has a test, and each test fails when the corresponding fix is reverted.
- The colour test renders the real wall, area and shortcut-slot markup with hostile values and reads the attributes back the way a browser does.
- The installer test runs `install.ps1`'s git helper under Windows PowerShell 5.1 against a throwaway repository.
- The Cloud Manager tests run the real `cloud.js` and click the rendered controls' handlers.
- The full suite passes.
