WD Cloud Manager — hotfix for `showGroupShared is not defined` error that blocked the ledger from loading in v1.9.57.

Suite `v1.9.57 → v1.9.58`. WD Cloud Manager `v4.9.6 → v4.9.7`.

## What happened

v1.9.56 introduced a `Group Shared` filter card. v1.9.57 (via a mid-session decision) removed the card + backend field. The removal missed three dangling references inside `renderLedger`'s `pass()` function:

```js
const rowIsGroupShared = (row) =>
  directIsGroupShared(row) || anyChildMatches(row, directIsGroupShared);
// ...
if (showGroupShared) return rowIsGroupShared(row);
```

Neither `showGroupShared` nor `directIsGroupShared` existed anymore (deleted earlier in the same commit), so the first render call after login threw `ReferenceError: showGroupShared is not defined` — which the outer try/catch surfaced as the red *"Load failed: showGroupShared is not defined"* toast the maintainer saw.

## Fix

Removed the two lines. Ship as v1.9.58 / cloud v4.9.7 so the version bump forces the browser to re-fetch the JS.

## Verified

- Restarted Flask, loaded `/cloud`.
- Version chip: `v4.9.7`.
- Dashboard "All" count populated to 42 (real data, not `-`).
- 171 ledger rows rendered.
- No error toast.

## Files changed

- `web/assets/js/cloud.js` — deleted two dead references in `renderLedger`'s `pass()` function.
- `web/assets/versions.json`, `web/cloud.html` — version chip bump.

## Preventable

A grep for `showGroupShared` in my final v1.9.57 review would have caught this. Adding "grep for the removed identifier" to my pre-commit checklist for removal PRs.
