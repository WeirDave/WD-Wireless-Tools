Suite-wide cleanup pass. No user-facing feature changes — this release is about code health. Zero inline CSS anywhere in the frontend, dead classes purged, duplicate class families merged, brand-color literals swapped for CSS variables, comments removed suite-wide, and eight latent bugs fixed along the way.

Suite `v1.9.64 → v1.10.0`. Cloud `v4.9.15 → v4.10.0`. Walls `v7.26 → v7.27`. Report `v2.4 → v2.5`. Scale `v1.1 → v1.2`. Squirrel (Organizer) `v1.8 → v1.9`.

## the maintainer's ask

> "make sure that there's no duplicates and [any] stragglers make sure that the CSS files are intact and that we're not using inline CSS which I cannot stand … Let's make sure we've got groupings and utilize variables when possible … I like neatness and tidiness … no comments are necessary because you wrote the code and you're the only person touching it."

## What changed

### Inline CSS — gone

Every `style="…"` attribute is now a semantic class, or a native `hidden` attribute for `display:none`, or a CSS custom property (`--wall-color`, `--slot-color`, `--swap-swatch`, `--op-progress`, `--w`, `--h`, `--swatch`) for the small number of legitimately-dynamic values driven by data. Grep result: zero `style="` in any HTML file, zero static `style="` in any JS template literal.

Biggest single win: the **Hotspot report** in Report was 25+ inline styles building each stat tile, chip, and floor-plan marker from raw hex colors and pixel padding. It's now `.rep-hotspot-stat`, `.rep-hotspot-chip--android`, `.rep-mark--dir`, etc. — properly themeable and print-mode aware.

Second biggest: **Walls Template Sharing modal** had 20+ inline blocks including hardcoded `#1e77ac` / `#5fab4f` on the Import/Export buttons. Now uses canonical `.btn-blue` / `.btn-green` and a small set of `.tpl-*` classes.

Third: **Guides** — the three guide pages each carried a duplicated ~270-line `<style>` block. All three now link the shared stylesheet and reference `.guide-content` / `.guide-topbar`. Net delete of ~750 lines of duplicated HTML.

### Duplicate CSS classes — merged

- `.btn-secondary` + `.btn-sec` → single comma-selector rule (both selectors still work, one ruleset).
- `.main-menu .menu-item` + `.help-menu-item` → merged base rule; hover states kept separate because they intentionally use different tint tokens.
- `.main-menu .menu-sep` + `.help-menu-sep` → same treatment.

### Dead code — removed

**CSS**: 55 orphan classes deleted — old Report layout (`.rep-picker-*`, `.rep-ap-list`, `.report-body/-sidebar`), old Walls chrome (`.save-tpl-row`, `.keybind-dropdown`, `.swap-canvas-hud`), old Cloud panels (`.pair-cell`, `.unmatched-*`, `.split-*`, `.tree-folder/-fhead/-fname`, `.mh-hint-*`, `.share-group-manage-btn`, `.bulk-share-emails-row`), old Organizer (`.result-moved/-skipped/-error`, `.action-bar-label`, `.login-*`), plus legacy `.theme-btn`, `.peek-group`, `.set-group/-label`, `.wd-nav`, `.dz-nav`, `.logo-slot`, `.tip-pop`, `.mv-item-newname`, `.pair-code/-name`, `.dropzone-title`, `.dup-explain-actions`, `.progress-icon/-name/-detail`.

**JS**:
- Cloud: nonsense ternary at line 185, empty `chip()` helper, no-op `cancelBulkProgress()`, `_mhInit()` whose only remaining job was deleting a non-existent element.
- Report: entire `renderBomReport` code path (~150 lines) — BoM tile was `status:'coming-soon'` gated and unreachable. Also `apHasExternal`, `isExternalAntenna`, `PREVIEW_BOM`, unused `flagExternal` sidebar checkbox.
- Scale: `formatFeetInches` and `formatMetersMM` — exported but never called.
- Walls: `state.dragAdditive` (never read), `state._debug` (never read), `|| true` dead guard in `applyQuickSwap`.

**HTML**: 3 stray comments in scale.html.

### Duplicate helper — consolidated

`safeColor(c)` was defined identically in `walls.js` and `walls-swap.js`. Moved into `wd-shared.js` as `WD.safeColor` with `window.safeColor` alias. Local copies deleted, all callers resolve through the shared version.

### Comments — purged

Every `/* */` and `//` in every `.css`, `.js`, and `.html` file removed. Zero remaining. Python left alone. Section headers now use blank-line separation.

### CSS variables — extracted

19 literal brand-color values swapped for `var(--blue)`, `var(--green)`, `var(--amber)`, `var(--red)`, `var(--navy)`, `var(--purple)`, and their `-dark` variants. Root palette already had the tokens; some ruleset bodies had drifted to literals over time.

## Bug fixes bundled with the cleanup

Since I was in these files anyway, I fixed several latent issues surfaced during the earlier audit:

1. **Cloud `_taPickNew` typeahead click was dead.** `onmousedown="…_taPickNew('${idx}', ${JSON.stringify(query)})"` interpolated a quoted JS string into a double-quoted HTML attribute — clicking "+ Create new site: X" did nothing (Enter still worked, hiding the bug). Rewritten to read the query from `dataset.query` on the row.
2. **Cloud `class="btn primary"` was silently unstyled.** Missing the `btn-` prefix; fixed to `class="btn btn-primary"`.
3. **Cloud nonsense ternary** at line 185 (`'Uploading '.length ? 'Uploaded ' : 'Uploaded '`) — collapsed to just `'Uploaded '`.
4. **Report `compass()` returned undefined for negative azimuths.** `(deg % 360)` in JS preserves sign for negatives → `dirs[-4]` = undefined. Now `((deg % 360) + 360) % 360` before floor.
5. **Report `hotspotBand()` mislabeled 6E channels 1–9 as 5 GHz.** Threshold was `<6000` MHz, so 5955–5995 MHz (6E channels 1/5/9) bucketed wrong. Now uses the same `>=5955` threshold `hotspotChannel` uses — bands and channel labels now agree.
6. **Report Hotspot cover said "N Access points" for a phone-detection report.** `renderCover` / `renderInlineHeader` now take an optional `countLabel`; hotspot report passes `"Phones detected"`.
7. **Organizer shift-click crashed after rescan.** `_lastChecked` held a reference to a checkbox that no longer existed in the DOM. Reset to `null` at the top of `renderPreview`; shift-branch guarded with `if (!_lastChecked || allCbs.indexOf(_lastChecked) < 0)`.
8. **Organizer `toggleSite` selector injection.** `[data-site="${siteName}"]` broke when a folder name contained `"` or `\`. Now `[data-site="${CSS.escape(siteName)}"]`.
