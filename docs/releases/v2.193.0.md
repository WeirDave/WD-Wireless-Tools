# Dev toolbar: the one-off "Realign renamed cloud projects" action is removed

Suite **2.193.0**. No tool's own version changes. The dev toolbar is not part of any single tool.

## What changed

### Dev toolbar

- **The "Realign renamed cloud projects…" button is gone from the dev toolbar**, together with its panel and the whole-account endpoint behind it. It was a one-time repair for a bulk cloud rename that left many pairs reading "cloud newer". That repair has been run and is no longer needed.
- The toolbar now carries **Clean up leftover files…** and **About dev mode**.

### Cloud Manager

- **Unchanged.** Cloud Manager's own reconcile action for selected rows uses the same comparison and writes the same way. It works as before.

## Verified

- The full test suite passes.
- The dev toolbar's browser tests still cover the strip, the password gate, the panels, and the colours of the preview and live controls, now checked on the clean-up panel.
- Cloud Manager's reconcile endpoint tests still drive the real function.

## Files changed

- `web/assets/js/wd-dev-actions.js`: the realign button, panel, report renderer and progress display removed
- `server.py`: the `realign_renamed` endpoint removed; `reconcile_pairs` unchanged
- `web/assets/wd-tools.css`: the styles only the realign panel used removed
- `tests/test_dev_toolbar_report.py`: removed
- `tests/test_dev_toolbar_browser.py`, `tests/test_dev_toolbar_does_not_print.py`: realign tests removed; shared checks now run on the clean-up panel
- `tests/test_cloud_realign.py`: the removed endpoint's check dropped
