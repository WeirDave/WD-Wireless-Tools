Two Squirrel discoverability fixes in one release: **Create Project Folder now lets you pick which subfolders to create** — which is what "custom destinations" should have meant end-to-end from the start. And every Squirrel screen now points at Settings so nobody has to guess that the hamburger menu holds every knob.

Suite `v1.27.0 → v1.28.0`. Squirrel `v1.18 → v1.19`.

## What's new

### 1. Pick your subfolders when creating a project

Previously, **Create Project Folder** blindly built every destination in your config into every new site folder — three built-ins plus any customs. That's fine for the common case but wrong the moment a project doesn't need one of them.

Now the Create Folder modal has a **Subfolders to create** section with a checkbox per destination — the three built-ins, plus any custom destinations you've configured. All checked by default. Uncheck any you don't need for this particular project and only the checked ones get built.

The picker shows the destination's on-disk name (honoring any renames from Settings), colored with the same swatch the summary chips use, and tags custom destinations with a small teal "custom" pill. If your config has renamed `reports/` to `docs/`, the checkbox reads `docs`.

A hint under the picker links straight to Settings for renaming or adding destinations, so users who realize they need something new can get there without hunting through the hamburger.

**Backend.** `create_project_folder(name, root, subfolder_keys)` now accepts an optional list of destination keys. When present, only those destinations become subfolders; when absent, all configured destinations are used (backward compatible — any old client that doesn't send the field still gets the historical behavior). The server dispatch in `server.py` forwards `d.get("subfolder_keys")` so the field is optional.

### 2. Settings finally has visible on-ramps

The v1.27.0 Custom destinations feature was buried behind the hamburger menu with zero on-page hint. Fixed:

- **Pick screen**: a dashed-border hint below the two action cards spelling out what Settings can do — "rename destinations, add custom ones (route `.csv` to `raw-data/`), or set bulk rename patterns" — with an `⚙ Open Settings…` button.
- **Preview screen toolbar**: a `⚙ Settings` button next to Rescan, tooltipped as "Rename destinations, add custom destinations, set rename patterns".
- **Preview screen hint row**: below the bulk-move buttons, a small `Files route to the destinations above based on their extension. Rename destinations or add a new one…` line with an inline link.
- **Create Folder modal**: the subfolder-picker hint links to Settings so the "I need to add a destination" thought has a one-click landing spot.

Every place a user might wonder "where do I change this?" now answers itself.

## User-visible behavior change

- **Create Project Folder** modal has a new **Subfolders to create** section between the folder-name input and the action buttons.
- **Squirrel Settings** is now reachable from the pick screen (dashed hint below the cards), the preview toolbar (`⚙ Settings` button), the preview bulk-move row (inline link), AND the Create Folder modal (inline link under the picker) — not just the hamburger menu.
- The **Configure Squirrel** card that briefly appeared as a third pick-screen action in the working session was replaced with the hint above; the pick screen still shows only the two primary actions.

## Verification

1. Open Squirrel → **Create Folder…**. The modal shows a "Subfolders to create" grid with **images**, **floorplans**, **reports** checked. If you have custom destinations, they appear as extra checkboxes tagged "custom" in teal.
2. Uncheck `reports`, enter a folder name, and Create. Open the folder on disk — only the checked destinations exist.
3. On the pick screen, the dashed hint below the two cards has an `⚙ Open Settings…` button that opens the same modal as the hamburger's Settings entry.
4. On the preview screen, click the `⚙ Settings` button in the toolbar or the "Rename destinations or add a new one…" link below the bulk-move buttons. Both open Settings.
