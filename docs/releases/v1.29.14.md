*"So somehow the AP names/numbers ended up wrong?"* — then, on the follow-up, *"You should be getting the AP name from the file directly. Also not everyone names APs the same way — make it an option, and add a legend."* — Dave, on the SITE1 report.

The Directional Antenna Installation and Antenna Aim reports were inventing their own row numbers — 1, 2, 3… — which meant a marker labeled "1" on the plan bore no relation to whatever the AP was actually called in Ekahau, and floor 2's counter reset even though the APs numbered continuously in the customer's own naming. Dave's fix: use the AP name straight from the `.esx`.

**Marker labels now come from the AP name.**

- Default (**Short number labels on the plan** — on): when an AP name ends with an `AP` designator (e.g. `SITE1-B1-01-01-AP42`), the marker and the `#` column show just the trailing part (`42`). Every project that follows this convention lines up automatically.
- Names that don't have that suffix (MACs, free-form labels) get their full name on the marker, with the font scaled down so long text still fits inside the dot.
- Toggle **off** to force full names on every AP regardless of pattern — safer when the AP number in the name isn't the identifier you actually care about.
- Every floor's overview carries a small legend line stating which mode is active, so the printed PDF is self-documenting.

**Also in this release**

- Floors on the placement report now render in name order (numeric-aware — floor `10` sorts after `9`, not after `1`). Floor 02 was rendering before floor 01 on the SITE1 project.
- New **User Guide** page at `/guide-report`, linked from the WD Report menu — covers report templates, marker labels, filtering + grouping, cover pages, and printing.
- README paragraph explaining the marker-label design.
