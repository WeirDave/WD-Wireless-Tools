Home page redesign — version pills moved next to titles, layout no longer needs scrolling on most monitors, and the auto-release title bug is fixed for good.

## What changed

### Home page version pills
Moved off the top-right corner of each card (muted gray, easy to miss) to sit inline right next to the tool title, in white, at a slightly larger size. Still the same pill shape.

### Card row layout — flexbox instead of CSS grid
With 5 tools, the last row only ever holds one or two cards. CSS Grid pinned that leftover row to the left column, which read as disjointed. Switched `.cards` to a flexbox with `justify-content: center`, so however many cards land on the last row, they center under the row above instead of hanging off to one side — at any window width.

### Tighter spacing, viewport-aware logo
The header logo was a fixed 340px-wide square plus generous margins throughout — added up to enough vertical space that even a large monitor needed to scroll to see the bottom row of tools. The logo now scales off viewport height (`clamp(150px, 20vh, 300px)`) instead of a fixed size, and header/card/footer spacing was trimmed across the board. Both rows of cards now fit without scrolling on a standard large-monitor window, and it still degrades gracefully on smaller screens (1366×1080 confirmed).

### Removed the "runs locally on your machine" footer line
Redundant — the person looking at the page already knows it's running locally.

### Fixed: auto-created GitHub releases had bare-tag titles
`.github/workflows/release.yml` set the release title to just the tag (e.g. `v1.9.7`) instead of `WD Wireless Tools v1.9.7`, breaking the naming convention every hand-created early release followed. Fixed the workflow, and backfilled titles on every affected release (v1.8.40–v1.9.7) to match.
