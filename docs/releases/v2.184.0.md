# Cloud Manager: site names copy with one click

Suite **2.184.0** ships **Cloud Manager 4.75.0**. The Cloud Manager page shows the Cloud Manager number, not the suite number.

## What changed

### Cloud Manager: copying a site or folder name

- **On the Sites tab, clicking a site's name copies it to the clipboard.** This works on both sides of the row: the cloud site name on the left and the local folder name on the right. A confirmation appears at the bottom of the screen naming what was copied.
- The name is copied exactly as stored. On a pair whose names differ, the character highlighting is not included.
- Hovering a name shows a dotted underline and the tooltip **"Copy the site name"** (cloud side) or **"Copy the folder name"** (local side). The name is also reachable with Tab and copies on Enter.
- **Clicking anywhere else on the row still opens and closes the site**, as before. The chevron, checkbox and **⋯** menu are unchanged.
- **Dragging across text on a site row to select it no longer closes the site.** Before this release, the click at the end of a selection toggled the row, so the site folded away under the selection.
- Project names (the rows inside a site, and the Projects tab) are unchanged.

## Verified

- New tests render the real site row, pull the copy control back out of the rendered markup and run it against a recording clipboard. Both the cloud and local names reach the clipboard exactly as stored, including a name with an ampersand, an apostrophe and quotation marks, and on a mismatched pair.
- When the clipboard is refused, the copy falls back to the older copy command. If that fails too, an error names the reason.
- The real row-toggle listener opens the site on a plain click, and does nothing on a click on the name or a click that ends a text selection.
- Each new test was confirmed to fail with the change it covers reverted.

## Files changed

- `web/assets/js/cloud.js`: the copy control on site and folder names, its handler, and the selection check on the row toggle
- `web/assets/wd-tools.css`: styling for the copy control
- `tests/test_cloud_site_name_copies.py`: new tests
