WD Cloud Manager — dashboard filter cards shrunk from big buttons to compact counter chips. Same functionality, half the vertical space.

Suite `v1.9.29 → v1.9.30`. WD Cloud Manager `v4.6.5 → v4.6.6`.

## The problem the maintainer flagged

The dashboard filter cards (All / Mismatches / Orphans / Cloud Only / Local Only / Synced) were huge — big number, block layout, 3D lift on hover, ~68px tall each. At 35 sites, filters are more of a health-check glance than a slicing tool, and the Owner toggle already lives right next to `+ New Site`. The cards were eating a lot of vertical toolbar real estate for a job the user rarely needed.

## The fix

Compressed each card to a counter-chip layout: inline number + label, 25px tall, ~64–100px wide. Colored left-border and hover backgrounds remain (still clickable filters), but the 3D lift, big shadow, and 22px number are gone. The dashboard row is now 39px tall (was ~90px) — 55% smaller.

Reads as `42 All  ·  0 Mismatches  ·  1 Orphans  ·  0 Cloud Only  ·  2 Local Only  ·  39 Synced` in one horizontal strip.

Same click-to-filter behavior, same active-state color fills, same per-category color coding. Just visually receded so the actual ledger gets more of the viewport.

## Files changed

- `web/assets/wd-tools.css` — `.dash-card` layout: `flex-direction` inline, smaller number/padding, hover reduced to background swap (no more lift). `.dashboard` padding trimmed.
- `web/assets/versions.json`, `web/cloud.html` — version chip bump.
