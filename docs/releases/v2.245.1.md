# Home: tile outlines and names are back in each tool's own colour

Suite **2.245.1**. Tool versions are unchanged.

## What changed

### Home

- **Every tile has an outline in its tool's colour again.** The nine tiles carry the same colours as the tool pages: AP Labeler purple, Capacity azure, Cloud Manager blue, PlanTrim teal, Prep lime, Quick Walls green, Report rose, Scale red and Squirrel amber. The outline was neutral grey in 2.245.0 and is 2.5px in the tool's colour, as it was before 2.244.0.
- **Tool names are in the tool's own colour, unmixed.** In 2.244.0 and 2.245.0 the names were lightened on the dark theme and darkened on the light theme. They now use the same colour as the outline and the icon.
- **PlanTrim and the lighter colours match the tool pages in both themes.** On the light theme PlanTrim, Quick Walls, Prep, Report and Squirrel no longer switch to darker variants.
- **The last tool opened is marked by its "Last opened" label and a light tint of its colour.** Its outline is no longer the only one in colour, since all nine are.
- Letter jump, tile order, grid columns, menus and everything else changed in 2.244.0 and 2.245.0 are unchanged.

## Verified

- Home was checked in the browser: all nine tiles show their coloured outline and name.
- The full suite passes.
