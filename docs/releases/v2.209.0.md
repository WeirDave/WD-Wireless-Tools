# A second functional review: merge, updater, settings, Report options and Visual Swap

Suite **2.209.0**: Cloud Manager **4.81.0**, Quick Walls **7.74.0**, Report **2.69.0**, Squirrel **1.30.0**, PlanTrim **2.3.0**, Prep **2.5.0**, Scale **1.7.0**, AP Labeler **2.18.0**, Capacity **1.10.0**.

A second review covered the parts of every tool the first one reached least, and re-examined the 2.208.0 fixes themselves. Each fix below was reproduced against the real code with invented projects first, and each carries a test that fails on 2.208.0.

## What changed

### Updating, settings and installing

- **"Update now" works on an install that follows a branch.** The banner announced new commits on the branch, but the update compared release tags, did nothing and reported "Already up to date". It now fast-forwards the branch. A release install still moves to the newest release, and a developer's working copy is still refused.
- **A settings file that cannot be read is never overwritten.** A `settings.json` saved with a byte-order mark (Notepad's "UTF-8 with BOM", PowerShell 5), or otherwise unreadable, used to read as empty: the app sent its owner to Setup and the next save wrote defaults over every preference. Such a file now reads correctly when it is only the byte-order mark, and otherwise every save is refused with a message naming the file; pages still open. **Settings → Import** remains the way back and copies the damaged file aside first.
- **The install scripts stop on edited files** instead of discarding them, and name them. `install.sh` run inside an existing install no longer stops with a shell error after copying the new files, so its dependency update now runs.
- **A failed "Switch to git updates" is undone** rather than leaving a half-converted folder that refused a second try. The update panel, and `install.ps1`, say "Nothing was left half-installed" only when that is true; otherwise they name the kept copy of the previous version.
- **The log keeps 7 days as stated.** A log file from an earlier day was never rolled over at start-up, so it collected weeks of history.

### Cloud Manager

- **Merging several folders with "Keep newer" keeps the newest copy.** When a file existed in two sources and the destination, both sources were judged against the destination's original and the second overwrote the first, which could be the newest. The choice is now made against what the destination holds when each file arrives.
- **"Not a match", manual pairings and External marks follow the file** through **Move to site**, rename, **Flag for review** and merge. They used to be lost, and an unwanted automatic pairing came back.
- **Mine shows projects owned in the cloud**, including ones a colleague created and then transferred. The local file's creator decides only for a file with no cloud copy.
- **Downloads from the Projects tab land in the paired local folder.** 2.208.0 fixed this for the Sites tab only; a cloud site paired with a differently named folder still got a new folder from the Projects tab and from **Sync everything**.
- **Duplicate Projects respects ownership.** "Delete all N extras" and "Keep newest" keep the newest copy that can be acted on, leave colleagues' copies out of the delete and name them. A cluster in which every copy belongs to someone else deletes nothing and says why.
- **An unfiled project's download leaves no empty folder behind** after it is moved into a site.
- **Expand all** on the Sites tab holds until the tab is left, sites opened by hand stay open, and a slow refresh can no longer draw an older list over a newer one.
- **A sign-in that expires partway through** an operation shows the plain sign-in message instead of a raw "401" error, and a failed download no longer leaves an empty site folder.
- Two merged files whose names differ only in capitals are flagged as a collision. Cancelling a reconcile reports a cancel.

### Report

- **Saved options apply to the first report picked.** AP Installation, the report the page opens on, showed the shipped options while saying "Your saved defaults", and the first change saved the shipped values over the saved ones. A change made just before switching report is no longer lost.
- **Every cover prints Client, Prepared by and Project ref**, and its orientation choice: Placement, Summary, BOM, Interference, Aim, Audit and Coverage left them out.
- **Change / Audit obeys its controls.** "Confidentiality notice in footer" prints, "Include cover page" decides alone, and the cover names both the earlier and the later file. Its Before count of directional APs uses the earlier file's antennas.
- **The title on the cover and header is the name on the PDF.** "Main Campus - Building C" was shortened to "Main Campus", and a file called "final" printed as "final".
- **"Reset to shipped defaults" resets only the panel's options**: the grid, crop, combined sections, typed client name and page orientation are kept, and Review shows the result.
- **"Toggle all" in the AP list acts only on the APs shown**, and the count stays right after a tick.
- **Metric is honoured throughout.** Placement labels and the Coverage cell-size table followed feet whatever the setting, and metric heights now print to two decimals (3.05 m, not 3.0 m).
- **The second line of each Placement label (model and height) prints at 7pt or more**; it was 5.8pt.
- An omni AP prints no azimuth on the Antenna Aim Sheet. The contents page no longer promises section sheets for a floor without a plan image. 2484 MHz prints as channel 14.

### Quick Walls → Visual Swap

- **Undo and redo go to the floor where the change was made**, so it can be seen. Undo on another floor used to restore a selection that was not on screen, and **Delete** then removed walls on the floor not shown.
- **Switching floors quickly shows the right plan** under the walls.
- **Pointing at a row in the sidebar keeps that wall lit**, and moving over the sidebar no longer lights walls hidden under it.
- **Delete also removes the wall points it frees**; shared points stay, and Undo restores them exactly.
- **A dragged sidebar width survives closing and reopening.** Walls with no type read "(no wall type)", and their row selects them.

### Squirrel

- **A CSV folder rename can no longer give a folder another site's name.** With ids ST1 and ST12, "ST12 Old Annex" was renamed to ST1's site. An exact id wins; a partial address match is marked "to check" and is not applied; each row shows how it matched.
- **CSV columns with spaces work.** "Site Code" becomes the token `{Site_Code}`, and a name still holding an unfilled `{…}` is not renamed. `{date}` and `{folder}` fill in with a CSV loaded.
- **Organize no longer creates a subfolder removed from Settings → Default subfolders** ahead of time; it appears only when a file goes into it, and Undo removes it. The preview's names follow the ticks and destination changes.
- **"Reset Defaults" leaves Default subfolders alone**, and **Migrate existing folders…** works after an earlier rename.
- Extensions typed without a dot are honoured; a "/" in a destination name is refused, naming the field. Create Folder's `{date}` is the local date. Floor plans Squirrel extracted are no longer listed as unreferenced. Saving a rename profile asks before replacing one of the same name.

### PlanTrim, Prep and Scale

- **"Suggest from the set" leaves floors already cropped as they are.** It used to replace the crop with the suggestion and save it.
- **Switching floors quickly in PlanTrim shows the floor selected**, so a box can no longer be drawn on one plan and saved for another; opening a second file quickly can no longer be described by the first.
- **PlanTrim crops SVG plans sized in pt, mm or inches where the box was drawn.**
- **A capacity template captured in Prep stays selected** instead of reverting to the saved default.
- **With a drawn box, Prep fits the placeholder area to the trimmed plan** instead of cutting it.
- **Scale reads more of what drawings say**: `5ft6in` (66 in), `4 1/2'` and `4-1/2'` (54 in), a bare `1 1/2` (feet), single-character fractions such as `24′ 7½″` and `3⅛"`, and `1,500 mm`. Text that cannot be read in full is refused rather than half-read.

### AP Labeler

- **A template picked, or a segment edited, over a project's adopted scheme is kept** for the next project.
- **Saved defaults that arrive late** no longer replace the scheme adopted from the open project.

### Capacity

- **The file gets the device count the template shows.** Rounding differed between the page and the writer, so the shipped "Office, Wi-Fi 6E (example)" at 25 people showed 75 devices and wrote 72.
- **The preview cannot go stale while a headcount is typed**, and **Apply** waits for the current preview.
- **Templates with names in other scripts each get their own file.**

## Verified

- Each fix has a test that runs the real code against invented projects and folders and fails on 2.208.0.
- Placement and AP Installation printed to PDF in Firefox from an invented 71-AP, two-floor project, in metric and in feet: no text under 6pt, no overlaps, nothing within 18pt of the edge.
- The full test suite passes.
