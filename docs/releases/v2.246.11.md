# AP Labeler: a "Clear floor" button removes the manual numbers on one floor

Suite **2.246.11**, AP Labeler **2.21.0**.

## What changed

### AP Labeler (manual numbering)

- **A "Clear floor" button clears the manual numbers on the floor shown and leaves every other floor as it is.** It is in the panel at the bottom of the naming panel when the order is set to "Manual (click order)", between "Undo" and "Clear all". It asks first, naming the floor and how many numbers will be cleared.
- **"Clear floor" can be undone** with "Undo" or Ctrl+Z, and is greyed out when the floor shown has no manual numbers.
- **"Clear all" is unchanged.** It still clears the manual numbers on every floor.

## Verified

- Tests drive the real button handlers: clearing one floor leaves the other floor's numbers and order intact, declining the prompt changes nothing, Undo restores the cleared numbers, a floor with no numbers asks nothing, and "Clear all" still empties every floor. The new tests fail when the handler clears every floor instead of one.
- The full suite passes.
