# The update button installs the update and restarts the app

Suite **2.246.20**. No tool version changes; every tool is unchanged.

## What changed

### About window (**About** in any tool's menu): updating

- **One press updates and restarts.** The update button (**Update now**, **Download and install update** or **Pull now**) installs the update and then restarts the app itself. The separate **Restart to finish** step is gone, and the page reloads on the new version once the app is back.
- **The release notes are shown after the restart.** The page that loads on the new version opens **About** on what was installed (for example "Updated v2.5.0 → v2.6.0"), headed **What's new in this update**, with the release notes of each version installed and a link to the full release history. A pull that brought commits without changing the version number shows no list, as before.
- **A restart that does not complete can be retried.** If the app has not come back after 30 seconds, the panel keeps the update result and shows **Try restart again**, with a note that the update itself is installed.
- **The release notes are also listed while the restart is under way**, below the progress line, until the page reloads.
- **Switching an install to git updates does not restart.** It does not change the version, so the app stays running as before.

## Verified

- The About window is opened in Chrome, Edge and Firefox with five invented releases offered. The update button is pressed with the install and restart requests answered by stand-ins, and the screen is read: the restart is requested once without any further press, the button reads "Restarting…" and is disabled, and the notes are listed. The page is then reloaded by the updater itself, and the reloaded page opens **About** on the installed version with the notes of exactly the releases installed and no restart button. With the automatic restart removed, all of these checks fail in all three browsers.
