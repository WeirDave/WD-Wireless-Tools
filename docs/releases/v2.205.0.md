# Quick Walls: a wall-type editor that fits the screen, and Delete says what it leaves behind

Suite **2.205.0**: Quick Walls **7.72.0**.

## What changed

### Quick Walls

- **The wall-type editor is laid out in two columns and fits a laptop screen.** **Edit** or **+ Add Wall Type** opens the editor with **Name** and **Color** on the first row, **Thickness** and **Keyboard Shortcut** on the second, and **Vertical extent** across the full width, so **Auto — floor to ceiling** and **Stops short of the ceiling** each read on one line. The four squeezed columns are gone. **Cancel** and **Save** stay at the bottom of the editor while the form scrolls, so they are on screen on a 1366×768 window too.
- **Larger text in the editor and the template dialogs.** Dialog titles are 18 pixels in the normal typeface instead of 13-pixel code type; field labels, explanations and values are 13–15 pixels. The same applies to **Save Template** and **Manage**.
- **Delete says how many drawn walls use the type.** Pressing **Delete** on a wall type that is drawn on the plan now asks with the number of wall segments that would be left without a type, and points to **Visual Swap → Quick swap by type** to move them first. A type no wall uses says so. The count is taken when **Delete** is pressed, so walls moved in Visual Swap are counted where they now are; the editor's "drawn segments use this type" line is refreshed when Visual Swap closes, too.
- **Wall cards fit their buttons on one line.** On a wide monitor each card is wide enough for **Set key**, **Edit**, **Clone** and **Delete** in a row; **Delete** no longer wraps onto a line of its own.
- **The opening screen says what Quick Walls is for**: "Your wall types and number keys, in any project", and the last step reads "**Save** a new copy and open it in Ekahau".

### User Guide

- The Quick Walls chapter describes the new **Delete** confirmation.

## Verified

- In headless Firefox at 1366×768, 1366×1080 and 2519×1279 with an invented project: **Save** in the wall-type editor is inside the window at every size, and each height choice is a single line. Before the change, **Save** was below the window at 1366×768 and each choice wrapped to four lines.
- In headless Firefox with an invented project whose wall type has three drawn segments: **Delete** asks with "3 drawn wall segments" and names **Quick swap by type**; answering no keeps the type; an unused type says no drawn walls use it; after the segments are moved to the other type, the counts follow them. Both checks fail on the previous version.
- The full test suite passes.
