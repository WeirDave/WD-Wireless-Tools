WD Cloud Manager — alphabetical section headers on the Sites tree + A-Z quick-jump nav to make scrolling any-sized site list one click.

Suite `v1.9.24 → v1.9.25`. WD Cloud Manager `v4.6.1 → v4.6.1`.

## What the maintainer asked for

"We used to have letter headers between the sites when they were alphabetically sorted — bring those back. And in place of the giant filter cards across the top, drop a row of A–Z chips in so you can jump straight to a letter. Especially once we have hundreds of sites, that's how you make it fast."

## The two pieces

**1. Alphabetical section headers on the tree.** The Flat view already inserted a `.ledger-group-head` before each new letter's first row. Tree view was sorting alphabetically but rendering as one continuous list. Now it emits the same header shape between letter groups — `A`, `B`, `C`, … stamped in both the Cloud Sites and Local Folders columns at the same y-offset. Alternating-row stripes reset per section so long groups don't march into a wall of same-color rows.

**2. A-Z jump-nav row** — new row of small clickable letter chips between the toolbar and the ledger, spanning the width. All 27 chips (`#` + A–Z) always render. Enabled chips (letters where at least one site exists in the current view) are bold and clickable; disabled ones dim to `--text-3` so you can see at a glance which sections have content without hovering. Clicking a letter smooth-scrolls the ledger to that section's header and briefly flashes the header (0.9s fade) so the eye lands cleanly instead of getting lost mid-scroll.

The nav rebuilds after every ledger repaint (search, filter, live refresh) so the enabled set always reflects what's rendered. Hidden entirely on the Duplicates tab since that view isn't alphabetically grouped.

## Details

- Section headers on both tree and flat use `data-jump-letter="<L>"` as the anchor.
- `_renderJumpNav()` runs at the end of `renderRows()` alongside `updateBulkBar` / `refreshSelAll`.
- `_jumpToLetter(L)` uses `element.scrollIntoView({ behavior: 'smooth', block: 'start' })` and adds `.jump-flash` for 900ms.
- Owner filter, status filter, and search all narrow the "enabled" set naturally — search "F" then click F and you're at the only match.

## Verified in the preview

Reloaded with the maintainer's real data:
- Jump nav: 27 chips rendered, 16 enabled (A B C D F H I L M O P S T U V W) — matches the letters actually present in the site list.
- Tree headers: 16 rendered, one per enabled letter, in alphabetical order.
- Clicking `C` scrolled the C section into view and applied `.jump-flash` on its header. Same for other letters.
