# Cloud Manager: downloading the cloud copy is no longer refused when both copies hold the same design

Suite **2.235.6**, Cloud Manager **4.90.4**. Every other tool is unchanged.

## What changed

### Cloud Manager (the **Cloud newer · download** and **Download over local** actions on a row)

- **A download is refused only when the local file holds something the cloud copy does not.** Previously the download stopped with "Not downloaded — your local copy is the newer one" whenever the date stored inside the local file was later than the cloud project's date, or whenever the local file had been rewritten since the last sync. The two dates come from different clocks, so a project saved to the cloud from Ekahau could leave the local file reading as newer even though both copies held the same design, and the only way through was to delete the local file and download again. The cloud copy is now compared with the local file before anything is refused: when the design is the same on both sides the download goes ahead, and the pair is recorded as in step afterwards.
- **A real local change is still protected.** If the local file differs from the cloud copy in anything other than dates and bookkeeping fields, the download still stops and leaves the local file untouched, and the message says the local file holds changes the cloud copy lacks. If the comparison cannot be made, for example because the downloaded copy cannot be read, the download is refused as before.
- **The comparison writes nothing, and is the same one the row's Check action uses:** the cloud copy is held in memory and the local file is only read.

## Verified

- A local file dated later than the cloud copy but holding the same design is replaced by the cloud copy. A local file rewritten since the last sync with the same design is replaced too.
- A local file that is newer and has additional access points is refused and left byte-for-byte unchanged, as is one rewritten since the last sync with a different design, and one compared against an unreadable download. With the comparison removed, the first two tests fail.
