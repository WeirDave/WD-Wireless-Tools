WD Cloud Manager — explicit **All** chip in the jump-nav so clearing the letter filter doesn't require remembering which letter you clicked.

Suite `v1.9.38 → v1.9.39`. WD Cloud Manager `v4.6.13 → v4.6.14`.

## The gap the maintainer hit

v1.9.37 introduced letter filtering via the jump-nav (click S → view narrows to S sites only). To clear the filter you had to click the same letter again — a known pattern from the dashboard status chips, but not discoverable if you didn't already know.

the maintainer's take: "multiple ways to do the same thing sometimes are better because you catch everyone's logic."

## The fix

New **All** chip at the start of the jump-nav row. Clicking it always clears the letter filter (sets `activeLetter = null` and re-renders). Highlighted with the same solid-blue "active" style used elsewhere when no letter filter is applied — so at rest, "All" reads as the current state.

Two paths to clear now:
- Click the active letter chip again (existing toggle behavior)
- Click **All** (new explicit escape hatch)

Both do the same thing. Also — clicking All when nothing's filtered is a no-op, so no accidental re-renders.

## Verified in the preview

- Baseline: **All** chip highlighted, 170 rows.
- Click S: **All** deactivates, S activates, 34 rows.
- Click **All**: All highlights again, no letter active, 170 rows back.
