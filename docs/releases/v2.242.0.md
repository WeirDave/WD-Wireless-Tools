# Report: choose which floors a report covers

Suite **2.242.0**. Report **2.75.0**. Other tools are unchanged.

## What changed

### Report

- **A report can cover some of a project's floors.** On the Configure step, below the report options, the new **Floors to include** card lists every floor plan with its building and AP count. Every floor starts ticked. Unticking a floor removes its sections, its APs, its rows in the tables and its share of the totals from the report.
- **Quick choices.** **Only** beside a floor includes that floor and leaves every other floor out. **All floors** and **None** at the top of the card tick or clear every floor. APs that sit on no floor plan have their own **(No floor plan)** row.
- **Every report follows it** except Change / Audit Report, which always compares the whole of both files and does not show the card. This includes Site Summary Sheet, Bill of Materials and Interference / Rogue Devices, which have no **APs to include** card: their counts, floor tables and per-floor maps cover only the ticked floors, and Interference lists only devices seen on a ticked floor.
- **The report says which floors it covers.** When any floor is left out, the cover (or the header, when the cover is off) shows a **Floors** line naming the floors included, or "2 of 9 floors" for a longer list. With every floor included nothing is added.
- **The cover's floor count** shows only the floors that remain.
- **The AP list and the AP schedule follow the floors.** The **APs to include** card lists only APs on ticked floors, and the **AP schedule (CSV)** button on the review step exports the same set.
- **A clear message when nothing is left.** If every floor is unticked, or every ticked AP is on an unticked floor, the preview names the **Floors to include** card instead of the AP list.
- **The choice lasts while the file is open.** Opening a project starts with every floor included, so a floor added to the building later is in by default. The card is hidden for a project with a single floor.

### User manual

- The Report chapter has a new section, *Choosing which floors appear*, and the note about the reports that skip the AP card is corrected.

## Verified

- New tests render the real reports from an invented three-floor project and drive the card's controls from the markup it renders: unticking, **Only**, **All floors** and **None**, and the report printed for each choice. The Bill of Materials, Summary and Interference totals match the ticked floors, the cover counts and names the floors that remain, and the open project is whole again after every render, including one that throws. Each rule fails when removed.
- Full test suite passes.
