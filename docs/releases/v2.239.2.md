# Report: the colour dots in a printed key are now printed

Suite **2.239.2**. Report **2.73.5**. Other tools are unchanged.

## What changed

### Report

- **The key under a floor plan now prints its colour dots.** The key reading *Access point* and *Directional cone shows aim* is shown under the Placement Map and the Antenna Aim Sheet floor plans. Its dots were left off the paper when printed from Firefox, so each label sat after an empty gap and the key could not be matched to the markers on the drawing. The dots now print in the colour of the markers they stand for, on every page that carries the key.
- **The directional label has no comma.** The key now reads *Directional cone shows aim*.

## Verified

- A new test prints a key through Firefox and checks that both a default-coloured dot and a colour-coded dot appear on the sheet. It fails without the change.
- Full test suite passes.
