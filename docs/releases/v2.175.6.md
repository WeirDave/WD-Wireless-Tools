# Opening screens scale smoothly with the window height

Suite **2.175.6** ships **Squirrel 1.27.8, Quick Walls 7.69.2, Prep 1.10.2, Capacity 1.4.3, PlanTrim 1.19.2, Report 2.65.4 and AP Labeler 2.13.3**. Each tool's page header shows that tool's own number, not the suite number.

## What changed

### Squirrel, Quick Walls, Prep, Capacity, PlanTrim, Report and AP Labeler: the opening screen

This is the screen each tool shows before a folder or an `.esx` is opened.

- **The logo and the spacing around it now scale continuously with the window height.** In 2.175.4 and 2.175.5 they switched between two fixed sizes, full size above 860 pixels tall and a smaller size below. Now every window height gets its own in-between size: about 76 pixels on a 650-pixel-tall window, about 104 pixels at 768, and the full 180 pixels from roughly 1080 pixels tall upward.
- **The opening screen fits without scrolling from about 650 pixels of window height upward on all seven tools.** That covers a laptop running Windows display scaling with the browser's tab bar and bookmarks bar showing, where the page gets much less height than the screen's resolution suggests.
- **Squirrel's cards also tighten their inner spacing on shorter windows.** All five stay in one row whenever the window is at least 1080 pixels wide, as in 2.175.4.
- On a tall screen the pages look as they did before 2.175.4. The logo never slides under the bar across the top of the page. Nothing needs to be turned on.

## Verified

- All seven tools were measured in a browser at window heights from 600 to 1440 pixels. From 650 upward every page fit without scrolling, and the logo grew with every step up to its full size. At 600 pixels, Squirrel alone needs a short scroll.
- The automated browser tests from 2.175.4 and 2.175.5 still hold. A new one checks that the logo gets bigger at each of three window heights and reaches full size on a tall window. The earlier two-size version fails it.

## Files changed

- `web/assets/wd-tools.css`: the two fixed sizes replaced by sizes that scale with the window height
- `tests/test_squirrel_home_fits_the_screen.py`, `tests/test_tool_landings_fit_the_screen.py`: the scaling check
- `web/assets/versions.json`, `README.md`: version numbers
