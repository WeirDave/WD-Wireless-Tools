# Cloud Manager: rename one side of a pair to the other side's name in one click

Suite **2.187.0** ships **Cloud Manager 4.77.0**. The Cloud Manager page shows the Cloud Manager number, not the suite number.

## What changed

### Cloud Manager: the rename dialog

- **Renaming one side of a matched pair can now take the other side's name with one click.** Before this release, the matching name was shown in the dialog but had to be typed by hand.
- **Where it is:** open **Rename this cloud project…**, **Rename this cloud site…**, **Rename this .esx file…** or **Rename this local folder…** from a row's **⋯** menu. Under the **New name** field, a button reads **Use "<the other side's name>"**, labelled **Matching local .esx file**, **Matching cloud project**, **Matching local folder** or **Matching cloud site**.
- **What it does:** it replaces the text in **New name** with the other side's name. The preview underneath shows the result before anything is renamed. Nothing changes until **Rename** is pressed.
- It appears on the Projects tab and on the Sites tab. It appears only when the item is paired and the two names differ.
- The existing **Insert "<site name>"** button is unchanged and sits beside it on the Projects tab.

## Verified

- New tests open the real rename dialog on a paired project and a paired site, find the button in what the dialog rendered, run it, and check the name field and the preview. Both directions are covered: cloud to local and local to cloud.
- The button does not appear when the names already agree or when the item has no partner.
- The tests were confirmed to fail with the button removed, and with its handler emptied.
