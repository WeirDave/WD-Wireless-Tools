# Cloud Manager: "Upload as a new project" removed

Suite **2.187.0** ships **Cloud Manager 4.77.0**. The Cloud Manager page shows the Cloud Manager number, not the suite number.

## What changed

### Cloud Manager

- **The "Upload as a new project…" and "Upload as a new cloud project…" actions added in 2.186.0 (Cloud Manager 4.76.0) are removed.** A paired row offers the same actions it did in 2.185.0.
- Nothing else in Cloud Manager changes. A cloud project already uploaded with the 2.186.0 action is not affected and stays in Ekahau Cloud until it is deleted there.

## Verified

- The full test suite passes with the action and its tests removed.

## Files changed

- `web/assets/js/cloud.js`: the 2.186.0 action and its handler removed
- `tests/test_cloud_upload_as_a_new_copy.py`: removed with it
- `web/assets/versions.json`, `README.md`: version numbers
