# Every tool's drop box is outlined in that tool's colour

Suite **2.175.8** ships **Report 2.65.5, PlanTrim 1.19.3, Prep 1.10.3, Capacity 1.4.4 and Squirrel 1.27.9**. Each tool's page header shows that tool's own number, not the suite number. Quick Walls and AP Labeler are unchanged.

## What changed

### Report, PlanTrim, Prep and Capacity: the opening screen

This is the screen each tool shows before an `.esx` is opened.

- **The dashed "Drop .esx file here or click to browse" box is now outlined in the tool's own colour all the time, not only when the pointer is over it.** Before, only Quick Walls (green) and AP Labeler (indigo) did this; the other four showed a grey outline that was easy to miss against the dark background.
- The colours are: Report rose, PlanTrim teal, Prep lime, Capacity azure (the colours of their tiles on the Home page, and of the title for Report and PlanTrim). The `.esx` in the box's text uses the same colour.
- Hovering over the box, or dragging a file onto it, fills it with a light tint of the same colour. Prep and Capacity used to switch to the suite's default blue at that point, and PlanTrim changed only the outline.

### Squirrel: Rename → Load CSV

- **The "Drop a .csv file here or click to browse" box in the Load CSV Site Directory dialog is outlined in Squirrel's amber**, and fills with a light amber tint on hover or while a file is dragged over it. It was grey, turning blue on hover.

Nothing needs to be turned on.

## Verified

- All six tools' opening screens and the Squirrel Load CSV box were opened in Firefox, Chrome and Edge, and the outline colour read back from each: every box carries its tool's colour, and all three browsers agree.
- A new automated browser test checks, in all three browsers, that each of the six drop boxes is outlined in a colour that is not the neutral grey, that the `.esx` text matches it, and that no two tools share a colour. The previous stylesheet fails it on Report, PlanTrim, Prep and Capacity.

## Files changed

- `web/assets/wd-tools.css`: one colour per tool for the drop box, replacing separate rules that covered only some tools
- `tests/test_tool_landings_fit_the_screen.py`: the colour check
- `web/assets/versions.json`, `README.md`: version numbers
