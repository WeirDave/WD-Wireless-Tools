# AP Labeler: Nearest Neighbor ordering can start from any chosen AP

Suite **2.240.0**. AP Labeler **2.20.0**. Other tools are unchanged.

## What changed

### AP Labeler: choosing where Nearest Neighbor starts

Applies to **4 Ordering → Nearest Neighbor**, the default ordering.

- **Clicking an AP on the plan makes it the start of the walk for that floor.** That AP is numbered first, and each following number goes to the closest AP not yet numbered. The chosen AP is ringed on the plan, and hovering any AP shows whether clicking it will start the walk there.
- **Clicking the start AP again returns to the automatic start.** The text under the Ordering list reads *Auto: starts at the AP nearest the top-left* or *Starts at … (ringed on the plan)*, and a **Use automatic start** button appears beside it while a start is chosen.
- **The start is set per floor** and is kept while the project is open. Opening another project clears it.
- **Preview table, plan markers and the downloaded file all follow the chosen start.**
- **Other orderings are unchanged.** Manual (click order) keeps its own meaning for a click on an AP, and the row, column and radial orderings do not use a start AP. **By Colour Groups** continues to start each colour at the AP nearest the top-left.

## Verified

- The route begins at the chosen AP for every AP picked across many generated layouts, with every AP present exactly once.
- A start that is not on the floor, or no start, gives the automatic result.
- Clicking sets, changes and clears the start for the floor on screen only, does nothing in other orderings or on the Unplaced tab, and ignores the click that ends a pan. Each of these checks fails when the behaviour is removed.
- The full suite passes.
