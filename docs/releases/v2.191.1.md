# Security hardening from code scanning

Suite **2.191.1** ships **Report 2.66.3**. The Report page shows the Report number, not the suite number. Nothing about how any tool is used has changed.

## What changed

### Report

- **Opening a project from disk reads only the file chosen in the file picker.** When Report opens a project through the system file dialog, the dialog hands the page a path, and the page asks the local server for that file's contents. The server now serves only a path its own picker returned in the same run, so a request cannot name some other file on the machine and read it. Choosing a file in the dialog works exactly as before.
- **Grouping by model** splits the vendor and model at the first separator only, so a model name that itself contains `|` is shown whole.

### Server

- **A request that fails inside a tool is now written to the log file.** Tools that catch an error and show its message on the page previously left no record of it in `wd-wireless-tools.log`. The message the page shows is unchanged, and no traceback is ever sent to the page. The log file's location is in **About → Diagnostics**.

### Release automation

- **The release-notes workflow no longer checks out the commit of the run that triggered it.** It runs from `main` and reads the released version from that commit as data, and it acts only on a successful release run from `main` in this repository.

### Maintenance scripts and tests

- Several test and audit patterns were rewritten so they cannot backtrack exponentially or miss a `</script >` end tag, and a reverse-engineering capture script now matches Amazon S3 hosts by hostname rather than by substring.

## Verified

- A file returned by the picker opens and names its folder; an existing `.esx` the picker never returned is refused with 403 and none of its bytes; the picker route records what it hands out.
- A route whose action raises answers with the same message as before and writes one log entry for a server fault, none for a missing field, and never a traceback.
- The full test suite passes.
