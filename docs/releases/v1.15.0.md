Squirrel now flags cross-site duplicate files during the scan. Advisory only — nothing gets moved — but you finally know when the same `logo.png` (or floor plan, or template) is sitting in three different site folders eating disk.

Suite `v1.14.0 → v1.15.0`. Squirrel `v1.12 → v1.13`.

## What's new

Every `scan()` call now walks each site folder (including its `images/floorplans/reports/` subfolders) and keys every file by `(name.lower(), size)`. Any key that appears in **≥ 2 distinct site folders** becomes a duplicate group. Groups are sorted by wasted disk space (largest file × most copies first).

The preview screen picks this up in two places:

1. **Summary chip** — a new amber `N duplicates` chip appears in the summary bar. Click it to scroll to the group listing.
2. **Group listing** — a full amber-accented section at the bottom of the preview showing each group's name, size, copy count, and every path where it lives (relative to each site folder).

Detection is filename + size, not content hash. That's cheap enough to run on every scan, and false-positive rate is negligible for the "same asset copied across sites" use case the maintainer was hitting.

## Verified end-to-end

Real 3-site test folder:

```
SITE3/images/logo.png    (25 B, "hello world same content")
SITE2/images/logo.png    (25 B, "hello world same content")
SITE4/logo.png          (25 B, "hello world same content")
SITE3/unique.txt         (10 B, "different")
```

Scan result: `duplicate_count: 1`, one group with all 3 paths, each rel path correctly showing subfolder location (`images/logo.png` vs bare `logo.png`).

Rendered preview: `.chip-dupes` visible with amber accent, `.org-dup-section` renders below the site list with the amber left-border, and `.org-dup-locs` shows all 3 paths in a mono font.
