# Prep: the floor plan view zooms and pans, and has a Fit button

Suite **2.192.0** ships **Prep 1.15.0**. The Prep page shows its own tool number, not the suite number.

## What changed

### Prep's floor plan view

- **Where:** Prep, card **2 — What that would do**, the floor plan view above the step cards. The view appears when **Trim the canvas** is ticked and a project is open.
- **Scrolling the mouse wheel over the plan zooms in and out**, centred on the point under the pointer. Each step is the same size as in PlanTrim, and the plan can be magnified up to twenty times, which makes the dashed crop line checkable against the drawing's walls.
- **Dragging the plan moves it.** The middle mouse button, the right mouse button, and dragging with the Space bar held also move it, as elsewhere in the suite.
- **A new "Fit" button**, above the right-hand edge of the plan, shows the whole sheet again. When a different floor is picked, or the margin changes, the view reframes to the whole sheet on its own.
- Scrolling over the plan no longer scrolls the page.
- A sideways swipe on a trackpad does not zoom.
- The plan is still drawn on a white page, with the paper being cut away shaded and the kept area outlined.

### Floor plan images

- Prep now detects the file type of every floor plan image. Previously it identified only CAD (SVG) plans. A plan whose format the browser cannot display now says so, instead of reporting a general display error.

## Verified

- The Prep page was run against a local server with a synthetic CAD project, in Chrome, Edge and Firefox. In each browser:
  - the plan was drawn on white;
  - one step of the real mouse wheel magnified it 1.15 times without scrolling the page;
  - a 150 × 60 pixel drag moved it by exactly that much;
  - **Fit** returned the view to where it started.
- The plan view's drawing, zoom, pan and **Fit** code is also run by the test suite:
  - in Node, against a recording canvas;
  - and in Chrome, Edge and Firefox, reading pixels back from the canvas.
- The test for a sideways swipe fails against the code before this fix.
