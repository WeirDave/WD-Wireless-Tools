# Every tool's header carries its own brand colour, set in one place

Suite **2.197.0**. No tool's own version changes; the change is to the suite's shared stylesheet.

## What changed

### All tools

- **Every tool now has one brand colour, used the same way on every page**: the header bar is tinted with it, the tool's name in the header is set in it, the drop box is outlined in it, and the current item on a workbench rail is highlighted in it. The colours match the tool's tile on the Home page:

  | Tool | Colour |
  |---|---|
  | Cloud Manager | blue |
  | Capacity | azure |
  | AP Labeler | purple |
  | PlanTrim | teal |
  | Prep | lime |
  | Quick Walls | green |
  | Report | rose |
  | Scale | red |
  | Squirrel | amber |

- **AP Labeler** is now purple throughout. Its header and drop box were indigo, while its Home tile was purple.
- **Scale** is now red throughout. Its header was purple, while its Home tile was red.
- **PlanTrim's** floor list now highlights the current floor in teal rather than Prep's lime.
- **Prep's and PlanTrim's titles in the light theme are darker** and now legible on their tinted bars. They measured 2.5:1 and 2.8:1; every title now clears 3:1 in both themes.
- **Quick Walls' title in the dark theme** is a true green instead of a mint that read close to PlanTrim's teal.
- Home, Settings, first-run setup and the User Guide stay neutral: they belong to the suite rather than to one tool.

## Verified

- Every tool page was opened in headless Chromium against the real server, in the dark and light themes, and its header photographed: each bar is tinted and each title is in the tool's own colour.
- The colours are resolved from the stylesheet the way the browser resolves them, including the light-theme overrides and colour mixing. Every tool page has a colour of its own, no two tools share one, and every title clears 3:1 against its own tinted bar in both themes. Giving two tools the same colour, or removing a tool's colour, fails the test.
- The browser test that measures the painted header now also covers Cloud Manager, Scale and Squirrel.
- The full test suite passes.
