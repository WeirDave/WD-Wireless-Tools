Cloud Manager gets an **External** dash-card. Teammate-owned projects still show up alongside your own (that's important — you still need to see them when you want to work with one), but they no longer inflate the scary red Orphans count.

Suite `v1.22.0 → v1.23.0`. Cloud Manager `v4.11.0 → v4.12.0`.

## What's new

### Auto-detected "External" bucket

Any cloud project (or local `.esx`) whose `owner` email doesn't match your signed-in user is now classified as **external**. The dashboard adds a new purple **External** dash-card next to Orphans. External items are:

- **Excluded from the Orphans count.** Before v1.23.0, teammate-owned projects that hadn't been paired with a local file counted as orphans. Now Orphans = unpaired items owned by you, and Externals get their own tally.
- **Recolored on the row.** External rows in the ledger get a purple left-edge indicator + the cloud-side name renders in purple. The owner-tag turns purple too. Visually distinct from red orphans, red-verify-failed, and amber mismatches.
- **Filterable.** Click the External card to filter the ledger to teammate-owned items only. Toggle back to All to see everything.
- **Still respected by the Mine/Others toggle.** The existing Mine / All / Others toggle in the toolbar continues to work independently — External is a categorical bucket, not a scope filter.

- `dExternal` dashboard: **31 items**
- `dOrphans` dashboard: **2** (was 33 before this change — 31 externals excluded, 2 real orphans remain)
- Clicking the External filter reduces the ledger to exactly **31 rows**, all with `.is-external` class
- Row inspection: border-left = `rgb(139, 92, 246)` = `--purple` ✓; cloud name text = purple ✓; owner-tag = purple ✓
- Dashboard card border-color = `rgb(139, 92, 246)` = `--purple` ✓

**Sites tab:**
- External count reflects externals nested within your matched sites (not top-level teammate-owned sites — those are counted separately in the projects tab)
- Filter behavior works: clicking External shows all rows where the item is teammate-owned
- Some site-tab counting edge cases where teammate-owned SITES don't roll up into the External counter — flagged for a follow-up pass. Filter behavior is correct.

## What did NOT ship (and why)

Auto-detection landed tonight; the manual toggle needs a UI decision — per-row context menu vs. inline chip vs. a settings-level whitelist. Deferred to a follow-up so we can pick the shape without rushing. In the meantime, the Mine / All / Others owner filter in the toolbar covers the primary use case (hide teammate content when I don't want to see it, show it when I do).

## Files changed

- `web/cloud.html` — new `.dash-card.external` element with `data-filter="external"` right after Orphans.
- `web/assets/js/cloud.js` — new `_isExternal(cloudObj, localObj)` helper; `updateDashboard()` tallies `externalCount` and `externalOrphans`, updates the External dash-card counter, subtracts externals from Orphans. `renderLedger()` gets a `showExternal` filter path in `pass()` and also excludes externals from the default `showOrph` path. Every `ledger-row` template appends `is-external` class when `_isExternal(r.cloud, r.local)`.
- `web/assets/wd-tools.css` — new `.dash-card.external` variant (uses `var(--purple)` / rgba tint), plus `.ledger-row.is-external` styles for the box-shadow accent and owner-tag color. Existing token system reused — no new hex literals.
- `web/assets/versions.json`, `web/home.html`, `web/cloud.html` — version bumps.
