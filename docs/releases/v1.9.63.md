Every polish that exists per-project (group members panel, Sync Group Shares chip, filtered share list, role tooltips) is now available in bulk mode. ## What changed

`openManageShares(projectId, projectName, bulkProjectIds)` now takes an optional third argument. When it's an array of IDs, the modal:

- **Title**: `Sharing N projects` instead of `Manage Sharing — <name>`
- **Sub**: `Add people, enable your Sharing Group, or both — applies to every selected project.`
- **Share list**: hidden (per-project shares differ; showing an aggregated list would be misleading)
- **Group toggle section**: fully visible, same as per-project
  - Manage Members chip: opens the members panel with the exact same UI
  - Sync Group Shares chip: fully functional (this action is global anyway)
- **Share-with-someone form**: fully visible; typing an email + Add fires `bulk_share` under the hood against every selected project
- **Danger Zone**: hidden (transfer ownership is deliberately per-project)

The toolbar Share button (`openBulkShare`) is now a 5-line thin redirect into `openManageShares` with the third arg populated. The old `#bulkShareModal` HTML is gone, along with its `_bulkShareCtx`, `_bulkShareRenderGroup`, `_bulkShareParseEmails`, and `_bulkShareApply` functions.

## Bug fix — 3× `hideModal is not defined`

the maintainer got a red toast: **"Bulk share failed: hideModal is not defined"** — after a successful 91-project share. The share succeeded but the modal-close call errored because I'd written `hideModal(...)` instead of `closeModal(...)` in three places this session (bulk share apply, sync group apply, transfer ownership commit). All three fixed.

## Behavior notes

- **Add People in bulk mode**: fires `bulk_share` (uses Ekahau's array-shaped share endpoint natively — one API call for the whole batch). Toast reports the count: *"Shared with user-a@example.com on 42 projects (3 skipped — not owner)"*.
- **Group toggle in bulk mode**: fires `bulk_share` with the group half — OFF-then-ON on `toggle-userGroup` so current group members get pushed to every selected project. Same guarantee as v1.9.59's Sync Group Shares.
- **Manage Members panel in bulk mode**: exactly the same as per-project. Add/remove members from the group globally. The Sync Group Shares chip finishes the loop.
