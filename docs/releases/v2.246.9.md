# Squirrel: the Select Folder button lines up with the other cards' buttons

Suite **2.246.9**, Squirrel **1.30.2**.

## What changed

### Squirrel (opening screen)

- **The "Select Folder…" button on the Organize Files card is on the same line as the buttons on the other four cards.** When a previously used folder was remembered, the "Last:" line and the "or continue with this folder" link were shown below the button, which pushed it higher than the rest. They are now shown above the button, between the card's description and the button, so the buttons stay level whether or not a folder is remembered.

## Verified

- A browser test with the remembered-folder line showing checks that the line sits above the button and that all five buttons end at the same height. It fails with the previous layout, where the Organize Files button ended about 100 pixels higher than the others.
- The full suite passes.
