# Quick Walls attenuation areas match what Ekahau stores

Suite **2.218.0**: Quick Walls **7.76.0**. Every other tool is unchanged.

## What changed

### Quick Walls

- **The Attenuation Areas presets are checked against a project drawn in Ekahau.** The file layout, the per-metre loss and the 2.4 / 5 / 6 GHz order are confirmed, so **"+ Add Tree Canopy & Shrubbery"** writes types that look exactly like ones created in Ekahau itself: no extra `key` field on a new type.
- **The shrub preset is named "Shrubbery/Low Plants"**, the name used in Ekahau, so a project that already has it is updated in place instead of gaining a second copy. Both presets use the colour `#193300`.
- **Existing types keep their name and colour.** Pressing **"+ Add Tree Canopy & Shrubbery"** on a project that already has them only sets the edges and the loss, and leaves the type unchanged, reporting nothing to save, when those already match. Ekahau's own rounding (9 ft stored as 2.7432000000000003 m) no longer counts as a difference.

## Verified

- A project that already holds both types in Ekahau's own layout is reported as already present.
- A new type carries no `key` even when copied from a stock type that has one, and an existing type keeps its name and colour.
- The suite passes.
