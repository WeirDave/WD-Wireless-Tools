WD Cloud Manager — letter section headers no longer stack into a wall at the top after scrolling. Dropped the sticky positioning that caused it.

Suite `v1.9.32 → v1.9.33`. WD Cloud Manager `v4.6.8 → v4.6.9`.

## The bug the maintainer hit

Clicked Q in Chrome, Edge, and Firefox — got a wall of 11+ stacked letter headers at the top of the ledger (all the A–P letters visually piled up in a small strip), with S content below. Q was there but sandwiched between the pile above and R/S below.

## Root cause

`.ledger-group-head` was declared `position: sticky; top: 36px;` so the current section's letter header would pin to the top as you scrolled. Nice idea in principle, but **CSS sticky siblings sharing the same `top` value all pin at the same position** — that's standard behavior across every browser. So after scrolling past A, B, C, D, F, H, I, L, M, O, P, every single one of those headers stayed pinned at Y=36. The verification confirmed 11 headers all reporting Y=36 simultaneously.

My earlier v1.9.32 fix (`position: static` on empty letters) only stopped the empty ones from stacking. Content-bearing letters still stacked because they share the same containing block and the same `top` value.

## The fix

Dropped `position: sticky` from `.ledger-group-head` entirely. Letter headers now scroll off with their content like everything else. The jump-nav + section color coding (blue Cloud / green Local backgrounds behind each letter) give enough section context — you can always see which letter section you're in from the sticky-free header of the section you're currently reading, plus the jump-nav highlights the current letter as an active section.

## Verified in the preview

Clicked Q from scrollTop=0. Result:
- Q header at viewY=-14 (essentially at the top of the container, barely off-screen)
- R at viewY=28
- S at viewY=70
- No A-P wall above anymore.

Before this fix, Q was at Y=36 (stuck under a wall of A-P also at Y=36); after, only Q/R/S are visible near the top.

## Files changed

- `web/assets/wd-tools.css` — removed `position: sticky; top: 36px; z-index: 3;` from `.ledger-group-head`. Removed the redundant `position: static` override on `.empty-letter` since the base rule no longer needs overriding.
- `web/assets/versions.json`, `web/cloud.html` — version chip bump.
