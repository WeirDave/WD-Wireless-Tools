WD Cloud Manager — hotfix. Toolbar Share button now lights up correctly when you check per-side cloud rows (e.g. Name Matches pairs in Tree view).

Suite `v1.9.59 → v1.9.60`. WD Cloud Manager `v4.9.9 → v4.9.10`.

## the maintainer's ask

> "The share button up top is not working after I click the check boxes next to it — the share button doesn't light up but we should have… the ability to change the sharing on those three files in the cloud"

Real bug I introduced when adding bulk-share ownership gating in v1.9.54.

## Root cause

`updateBulkBar`'s ownership check was:

```js
if ((d.kind === 'pair' || d.kind === 'cloud') && d.cloudId) {
  const ownerOf = (d.cloudOwner || '').toLowerCase();
  if (myEmail && ownerOf === myEmail) ownedCloudIds.add(d.cloudId);
}
```

Every rowData entry has `cloudOwner`, but the **ID field name differs**:

- **`pair`** rowData (`p:` / `ct:` keys) → `d.cloudId` is set
- **`cloud`** rowData (`c:` top-level, `ct-c:` tree-child cloud side) → `d.id` is set (NOT `cloudId`)

When Name Matches filter is active in Tree view, the visible rows are tree-child pairs. Checking a row usually ticks the CLOUD SIDE checkbox specifically (`ct-c:<id>`) — which is a `cloud`-kind rowData entry. My `d.cloudId` check hit `undefined` there, so the row didn't contribute to `ownedCloudIds`. Result: the Share button stayed disabled with the tooltip *"Select one or more cloud projects you own"* even though the user had just done that.

## Fix

Fall through both field names in the ownership check:

```js
const cloudIdOfRow = d.cloudId || (d.kind === 'cloud' ? d.id : null);
if ((d.kind === 'pair' || d.kind === 'cloud') && cloudIdOfRow) {
  const ownerOf = (d.cloudOwner || '').toLowerCase();
  if (myEmail && ownerOf === myEmail) ownedCloudIds.add(cloudIdOfRow);
}
```

## Verified in the preview

Steps run in the browser pane:

1. Reloaded `/cloud`, version chip `v4.9.10`.
2. Tree view + Name Matches filter active.
3. Ticked 3 cloud-side checkboxes (all `ct-c:` keys per DOM inspection).
4. Share button now enabled; tooltip reads *"Share 3 projects with people or your Sharing Group in one action"*.
5. `window._bulkShareOwnedIds` has all 3 IDs stashed for the modal.
