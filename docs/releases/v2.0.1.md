# WD Wireless Tools v2.0.1

This patch release prepares the clean v2 repository for public evaluation.

## Updates

- Corrected the README to distinguish the seven available Report formats from the Change / Audit report that is still in development.
- Updated installation output, project structure, hosted-site details, and component versions.
- Gave all eight Report template cards clearly distinct accent colors.
- Retained recognition of WaxFrame JSON report filenames in Squirrel.

## Privacy and security

- Ekahau project parsing for Quick Walls and Report happens locally in the browser.
- The application includes no telemetry.
- Saved Cloud sessions are encrypted, with the key stored in the operating system credential vault.
- Public examples and release assets use fictional, non-client data.

## Compatibility

- Windows and macOS.
- Python 3.10 or newer for the complete desktop suite.
- Quick Walls, Scale, and Report also run without the Python backend on the hosted site.

See the README for installation, first-run setup, privacy details, and troubleshooting.
