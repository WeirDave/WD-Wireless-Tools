WD Cloud Manager — jump-nav clicks now FILTER to that letter instead of scrolling to it. Cleaner and no scrolling required.

Suite `v1.9.36 → v1.9.37`. WD Cloud Manager `v4.6.11 → v4.6.12`.

## the maintainer's ask

"When we're in tree (which is where I'll live), and I click a letter, wouldn't it be better/cleaner to just show that letter?"

Yes. Clicking S to jump-scroll to S and then scan through S content is functionally the same as clicking S to view ONLY S — except the filter version has no scroll noise and no other letters below to distract from the current group.

## The behavior

- Click any enabled letter in the jump-nav → the ledger filters to only that letter's content. Full alphabet placeholders, unassigned projects, and held-back sections all hide. The chip in the jump-nav shows a solid blue "active" state.
- Click the same letter again → filter clears, full ledger returns.
- Click a different letter → filter switches instantly.
- Owner filter (Mine/Others) and status filters (Local Only, Mismatches, etc.) still stack on top — letter filter just narrows further.

Toggle-off matches the same interaction pattern the dashboard status chips use (click again to clear), so both filter families feel consistent.
