# Squirrel, Report's print step and Cloud Manager's duplicates read at arm's length

Suite **2.207.0**: Squirrel **1.28.0**, Report **2.67.2**, Cloud Manager **4.79.1**.

## What changed

### Squirrel

- **The file list under Organize Files is readable.** After **Select Folder…** and **Show File Details**, each file's row is 14 pixels (was 12), and the column headings, file-type tags such as **.PNG**, the new-folder badges and the per-site counts are 13 (were 10–11). The summary counts and the folder path are 14.
- **Rename's tokens and hints are readable.** The **Insert:** token buttons such as `{site_code}` and the hints under **Format:** are 14 pixels (were 12), and the **Load CSV**, **Gap Report**, **Profiles** and **CSV Helper** buttons are 13 (were 11).

### Report

- **The Review & Print step's own controls are readable.** The advice above the sheets on which PDF printer fills in the file name is 14 pixels (was 12), and each sheet's **Auto** / **Portrait** / **Landscape** buttons are 13 (were 11). The printed sheets are unchanged.

### Cloud Manager

- **Duplicate Projects shows each date once.** A file more than a week old read "September 21, 2026 at 2:13 PM · Sep 21, 2026"; it now shows the full date alone, and "· 3 days ago" is added only while it is recent.
- **Duplicate Projects is on the same text sizes as the list**: names 15 pixels, dates, sizes and the legend 14, and the **MIXED** / **LOCAL ONLY** / **matched** tags and counts 13 (were 9–12).

## Verified

- In headless Firefox with an invented folder of two sites' loose files, scanned by the real server: every row in the file list is at least 14 pixels and every heading, tag and badge at least 13. With the change removed, the check fails.
- In headless Firefox with invented duplicates a month and a day old: the month-old one shows one date and no "·"; the day-old one says "ago". On the previous version the month-old date appeared twice.
- Squirrel's Organize and Rename screens, Report's Review & Print step and Cloud Manager's Duplicate Projects tab looked at in headless Firefox at 1366×1080.
- The full test suite passes.
