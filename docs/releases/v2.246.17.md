# The "update available" notice is a small pill in the page header

Suite **2.246.17**.

## What changed

### Every page

- **An available update now shows as an "Update" pill in the top right of the page header, beside the Dark / Light toggle.** It replaces the full-width bar across the top of the page and the version badge in the bottom corner. The page is no longer pushed down while an update is waiting, and the notice has nothing to dismiss: the pill stays until the install is current. Hovering it shows what is available (for example "Update available: v2.247.0") and clicking it opens **About & Updates**.
- **On Cloud Manager the pill appears once signed in**, because the sign-in screen has no header.

### About & Updates (Menu, then "About & Updates")

- **The update area is now an "Updates" card.** The card title is on the left and the state of the install is on the right ("Version 2.247.0 is available", or the latest-release confirmation when the install is current). While an update is waiting the card has an amber outline and tint; otherwise it is plain.
- **The button that checks for updates is labelled "Check again"** and sits at the bottom of the card, below the release notes and the update button.
- **The update button names the version it installs**, for example "Update to v2.247.0", instead of "Update now". A checkout that follows a branch keeps "Update now", since a branch update does not change the version number, and a ZIP install keeps "Download and install update".

## Verified

- A browser test in Chrome, Edge and Firefox loads Home, Report, Scale, Settings and Cloud Manager with an update available. It checks that the pill sits directly against the theme toggle on the same row, that the page header stays at the top of the window, that neither the old bar nor the old badge exists, that clicking the pill opens About with the card marked and the update button naming the version, and that no pill appears when the install is current.
- The pill label and the card's status line clear 4.5:1 contrast against the amber tint in the dark and light themes.
- The full suite passes.
